反馈与诊断

生成本机诊断包，附在反馈里帮我们定位问题。诊断包只在这台机器上生成——你看到什么就发什么，提交与否完全由你决定。

关于隐私：SiteLens 无账号体系、无埋点、无遥测、无崩溃上报——开发者不接收你的任何扫描数据、目标信息或使用行为。 本页生成的诊断包不含 API Token、登录凭证、Cookie 与完整目标地址（路径只保留文件名）； 它不会自动上传，只有你点「提交」且配置了自己的收集地址时才会发出去。
未配置反馈提交地址（feedback.endpoint）。诊断包仍可一键复制，附到 仓库 Issue 里即可。 若你希望自动提交，可在自己的配置里填一个自建端点（内网亦可）——项目不提供、也不运营任何收集服务。
