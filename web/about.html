01

目标校验

协议白名单 + DNS 解析后逐 IP 校验，拒绝内网 / 环回 / 保留地址，防 SSRF 与 DNS 重绑定——工具自己不会被当成跳板。

全局限速、UA 自报身份，先读 robots.txt 再抓取；BeautifulSoup 把页面拆成 meta / 脚本 / DOM 命中等结构化证据。

03

指纹识别

7 个检测器对证据并行匹配，多来源独立命中自动提升置信度并去重合并，短词加边界防误报。

04

模板验证

05

情报关联

扫描器的纪律

安全工具首先要让人放心把它对准目标。这六条写进了代码，不是口号。

✓ 只读无害

Check 库只收只读类检测：不投破坏性 payload、不写数据、不打暴力点；POC 载荷在导入期即丢弃，不落盘、不执行。

✓ 主动默认关

主动验证、目录探测等模块默认关闭，需显式选择扫描等级并确认授权提示；登录爆破独立保留，不混入任何默认链路。

✓ 礼貌访问

全局限速（默认 0.4s 间隔）、UA 自报家门（SiteLens/1.0）、并发硬编码封顶、扫描前先读 robots.txt。

✓ SSRF 防护内置

协议白名单 + 主机黑名单 + DNS 解析后逐 IP 校验，环回 / 私有 / 链路本地 / 保留地址一律拒绝。

✓ 数据不出本机

扫描结果、知识库、历史记录全部存本地 PostgreSQL，不依赖云服务；SQL 全部参数绑定，通过静态安全审计。

✓ 来源透明

Nuclei、TscanPlus、OSV.dev、CISA KEV 等开源数据源全部署名；每条结论附原始证据，可逐条人工复核。

常见问题

「已验证漏洞」和「漏洞情报」有什么区别？

漏洞情报是「你用的这个组件，历史上存在过这些已知漏洞」，由识别结果自动关联，属于提示；已验证漏洞是引擎真实发出检测请求、拿到命中响应后的结论，附原始证据，属于证明。两者在结果里分开呈现。

扫描会影响目标网站吗？

被动指纹只抓取正常可访问的页面；主动验证全部使用只读无害 check（例如请求 /.git/HEAD 判断仓库泄露），不注入破坏性 payload，且全局限速。即便如此，也请只对拥有或获授权的目标发起扫描。

需要联网吗？数据会上传吗？

扫描目标需要联网，工具本身完全本地：Web 服务、数据库、报告导出都在你机器上。情报自动更新（OSV / KEV）默认每 24h 拉取一次，可随时关闭。

能扫登录后才可见的页面吗？

可以。扫描选项支持注入 Cookie 会话，爬取与检测带着会话执行，覆盖登录后才暴露的攻击面；认证前后的结果可分别查看。

识别结果准确吗？

每条技术标注置信度与命中证据（哪个响应头、哪个脚本、哪个 DOM 节点），多来源独立命中会提升置信度；情报侧用版本区间做三级判定，避免同名即报漏洞的误报。你可以逐条点开核对。

怎么接入我自己的流程？

扫描、历史、导出全部提供 REST API（Token 鉴权），可脚本化批量扫描；结果支持 JSON / 明细 CSV / 78 列宽表 CSV / 单文件 HTML 报告导出。
