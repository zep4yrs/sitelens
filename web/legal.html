隐私政策

生效日期：2026-09-12 ｜ 一句话版本：数据只在本机，开发者收不到，也永远不会要。

一、我们收集什么

什么都不收集。本软件无账号体系、无埋点、无遥测、无崩溃上报。 开发者的服务器不接收您的任何扫描数据、目标信息、机器信息或使用记录。

二、数据存在哪里

  • 桌面版：全部数据保存在 %APPDATA%\SiteLens （扫描历史 state、模板池 pools、插件 plugins、可变情报 data）， 安装目录仅含只读资产。
  • 浏览器模式：数据保存在引擎工作目录的 data\state， 外观偏好保存在浏览器 localStorage。
  • API Token 仅存储在本机（浏览器 localStorage / 配置文件），用于本机 前后端鉴权，不经任何第三方传输。

三、数据会发到哪里

仅在您主动触发时发生对外请求：

  • 对扫描目标：探测 / 验证请求（这是软件功能本身，仅限授权目标）；
  • 您主动点按的更新 / 同步：模板与情报更新（nuclei / afrog / NVD / OSV 等公开源）、 检查更新（桌面版拉取更新源清单）。

除上述外，引擎与页面不发起任何网络请求，不存在"后台上报"。

四、如何删除数据

设置页 · 数据管理 → 「清空全部扫描历史」可即时清空扫描记录 （设计为彻底删除，不经归档留底）；卸载桌面版时按提示选择是否一并删除 用户数据目录即可实现整体清除。

五、第三方组件

软件内置的开源组件及其许可证见本页《开源软件声明》； 这些组件在本地运行，不改变本政策的数据流承诺。

六、未成年人

本软件为专业安全评估工具，面向具备合法授权场景的从业者，不面向未成年人提供。

帮助与反馈

常见问题

  • 首次使用没有模板？桌面版模板池不随安装包：设置 · 引擎配置 → 执行 update-nuclei 在线拉取（约 700MB）。
  • 目标 robots 全站禁爬？引擎配置页关闭「遵循 robots.txt」（仅限授权目标）。
  • 桌面版怎么手动检查更新？托盘图标右键 → 检查更新。
  • 换电脑迁移？设置 · 数据管理 → 导出偏好；扫描历史整目录拷贝 %APPDATA%\SiteLens\state。

反馈渠道

  • 问题反馈：仓库 Issues
  • 反馈请附：引擎版本（设置 · 关于）、目标环境特征、脱敏后的请求 / 响应摘要； 切勿附带未授权目标的完整数据。
