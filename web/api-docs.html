REST API

全部接口同源访问，返回 JSON。扫描 / 批量 / 登录爆破为异步任务：提交后凭 job_id 轮询进度。 若服务端设置了 SLENS_API_TOKEN，/api/* 需携带 X-Token 请求头。

POST/api/scan

提交一次扫描（异步）。选项与 url 平铺在同一层 body（后端 data.get 顶层读取）：

{
  "url": "https://example.com",
  "deep": true,           // 同域浅爬取（默认开）
  "active_fp": false,     // FingerDir 主动路径指纹
  "dir_scan": false,      // 目录探测
  "dir_bypass": false,    // 403 绕过重试（需 dir_scan）
  "subdomain": false,     // 子域名枚举
  "service_probe": false, // 端口服务识别
  "browser_ua": false,    // 浏览器 UA 请求
  "webshell": false,      // WebShell 路径探测
  "netsec": false,        // 扫描内嵌 TLS / DNS 安全检测
  "dast": false,          // DAST + JS 攻击面提取
  "passive": false,       // 被动安全检测（Cookie 属性 / CSRF token，零额外请求）
  "weak_audit": false,    // 基础认证弱口令审计（需 dir_scan 发现 401 路径）
  "checks": "none",       // 验证引擎 none | core | all（all 追加 Nuclei 模板）
  "nuclei_cap": 300,      // Nuclei 单次模板上限（0 = 用配置默认；调大覆盖全部 4701 可运行模板）
  "auth_cookie": ""       // 认证会话 Cookie
  "login_mode": "form",   // 登录模式 form（表单）| json（JSON API）
  "json_endpoint": "",    // json 模式登录接口（空 = 登录页地址）
  "json_template": "",    // json 模式 JSON 模板（含 {user}/{pass} 占位符）
  "success_contains": ""  // json 模式可选成功响应特征
}
→ { "job_id": "a1b2c3d4e5f6" }
GET/api/job/<job_id>

轮询任务进度（扫描 / 登录爆破）：

{ "status": "running | done | error", "progress": 55,
  "message": "运行 7 个检测器…", "scan_id": null }
// status=done 时返回 scan_id；登录爆破完成时附 result.hits
POST/api/job/<job_id>/cancel

取消运行中的扫描 / 批量任务：引擎在阶段边界尽快停止；扫描取消后局部结果不入库， 批量取消后未开始的 URL 跳过。轮询到 status=cancelled 即为终态。

GET/api/captcha/capability

登录爆破验证码识别能力探测：{ "ocr": bool, "click": bool, "slider": bool }。

POST/api/batch
{ "urls": ["https://a.com", "https://b.com"] }   // 最多 50 个
→ { "job_id": "…", "total": 2 }   // 轮询 /api/job/<id>/results
GET/api/job/<job_id>/results

批量任务进度：{ status, progress, done, total, message }。

POST/api/audit

源码静态审计：multipart 上传字段 file（单个 .zip 压缩包，或单个 .py / .js / .php 源码文件），同步返回报告，文件审计后即删。上限见配置 audit 节（默认压缩包 20MB / 单文件 512KB / 最多 800 文件）：

{ "files": 12, "lines": 3401, "by_severity": {"high": 2, "medium": 5, "low": 9},
  "findings": [{"rule": "PY-SECRET", "severity": "high", "title": "疑似硬编码密钥/口令",
                "file": "a.py", "line": 12, "snippet": "…", "match": "…", "advice": "…"}] }
GET/api/audit/demo

对内置「故意漏洞」示例代码运行全部审计规则（教学演示，样本从不执行）。

GET/api/history?limit=50&tech=Next.js

扫描历史列表；tech 参数支持「哪些站用了某技术」反查（JOIN scan_techs 明细表）。

GET/api/history/<scan_id>

完整结果：technologies（含证据与版本）、verified（已验证漏洞）、vulnerabilities（情报三级判定）、 security（安全头评分）、extras（可选模块结果）。

DELETE/api/history/<scan_id>

删除一条扫描记录（含技术明细）。

GET/api/export/<scan_id>?fmt=json|csv|wide|html

导出。csv 为明细、wide 为 Wappalyzer 风格宽表（每类别一列）、html 为单文件离线报告。

GET/api/diff?a=1&b=2

两次扫描差异对比：added / removed / version_changed。

POST/api/netsec

独立网络层检测（只读）：{ "host": "example.com" } → TLS 证书 / 弱协议 / SPF·DMARC·MX 检测结果。

POST/api/loginbrute

登录爆破（异步，授权专属，必须 authorized=true）：

{ "url": "https://target.com/login", "authorized": true,
  "captcha_type": "none | digits | calc | click", "captcha_field": "captcha" }
→ 轮询 /api/job/<id>，完成后 result.hits = [{"user": "…", "password": "…", "url": "…"}]

安全约定

目标 URL 仅接受 http/https；DNS 解析后命中环回、私有、链路本地、保留地址一律拒绝（SSRF 三层防护）。
请求全局限速并携带 SiteLens/1.0 UA，遵循 robots.txt；主动模块默认关闭，仅限授权目标。
登录爆破独立于扫描等级链路，需显式授权确认。
数据库访问全部字面量 SQL + %s 参数绑定；zip 解包防路径穿越；POC 载荷不落盘、不执行。
