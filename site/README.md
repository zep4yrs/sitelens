# SiteLens 产品官网（分主题单文件）

- `index.html`：**亮色版（默认）**，完整产品介绍页；CSS/JS/图标/噪点全部内联，无外部字体、图片或脚本依赖。
- `dark.html`：**暗色版**，与亮色版内容、结构、交互一致，独立文件，不混排。
- `preview-desktop.png` / `preview-mobile.png`：亮色版 1440 宽桌面首屏与 390 宽移动端首屏预览。
- 下载按钮指向同目录 `SiteLens-Setup-5.2.3.exe`，部署时把安装包放在 `index.html` 同目录。
- 设计方向：SiteLens 自己的“证据台/扫描仪表盘”，不是 Pyisland 式居中大 Logo + 浮动胶囊导航的套壳。
- 文案口径：产品介绍，不是版本更新公告；版本号只出现在界面示意、部署区和页脚。
- 边界口径保留：G09/G10 默认关、完整矩阵未跑、PG 真机未验、内部签名版本。

部署：把整个 `site/` 目录放到任意静态服务器；安装包按 `SiteLens-Setup-5.2.3.exe` 命名放在 `index.html` 同目录。
