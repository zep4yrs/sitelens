# SiteLens v2.0.0 正式版（验证器）

验证型 Web 站点安全评估工具：指纹识别 → 漏洞情报关联（三级判定）→ 无害化验证 → 证据链交付。

## 本版主题：验证器

相对 v1.0.0 的核心升级——**每条发现都是可复核的验证结论**：

- **证据链四件套**：重放请求文本、响应快照（状态/尺寸/命中摘要）、通道命中信号明细、curl 一键复现命令
- **二次确认重放**：所有验证发现经独立重放确认，杜绝"一击即报"
- **实时动态面板**：扫描进行中实时滚动 引擎阶段 / 命中 / 403 绕过 / 认证 事件，命中与绕过计数持续高亮
- **结果页摘要卡**：按严重度 × 证据强度排序的「最值得关注」Top3，证据 n/5 量化

## 验证能力

- **盲注探测**：时间型（基线计时+双确认）+ 布尔差分（真/假 payload 双向验证）
- **403 绕过探测**：路径变异 × 信任头 × 改写头 × HEAD/OPTIONS 变体表（只读无害化，单扫描硬上限 60 请求）
- **SSRF 出带确认**：自托管 beacon（/b/<128 位随机 token>），目标回连即确认，不依赖外部服务（默认关）
- **反序列化入口面**：Java 序列化魔数探测（低危面信号）

## 认证态扫描

- 配置登录流自动登录（auth 段），或**自动发现登录表单**（password 输入框特征）填入凭证
- 捕获会话后爬虫 / DAST / 目录探测全链路带认证态

## 其他升级

- **Nuclei 模板库内置**：5400+ 可运行模板开箱即用（update-nuclei 仍可在线更新）
- **模板漏斗三前端**：nuclei path 形态 / raw 请求形态 / afrog 经典形态；`update-afrog` 镜像社区 POC 库
- **favicon icon_hash 指纹**：GitLab / Grafana / Jenkins / Tomcat / WordPress 等真实哈希内置
- **扫描选择器重构**：范围（Web/子域/端口服务）× 验证（被动/主动/深度盲态）× 强度（快速/标准/完整）三维合成
- **报告导出**：JSON / CSV / 宽表 CSV / HTML / **Markdown** 五格式
- govulncheck 依赖漏洞清零；GPL-3.0 开源

## Bug 修复

- **漏检面修复（重要）**：模板 `path` 字段的 string 单值写法被 YAML 解析层整模板静默拒收——官方模板库大量使用该写法，三前端重构后修复；同批补齐 raw 请求形态与 afrog 经典形态的转换
- **误报修复**：布尔差分的尺寸相似度比较存在整数除法截断（10.75% 被算成 10% 越过阈值），已改乘法比较
- **回归修复**：主动扫描路径上被动检测与 TLS/DNS 评分模块缺席（重构引入），已补回
- **安全修复**：govulncheck 扫描出的 8 项依赖漏洞清零（Go 标准库 7 项 + golang.org/x/text 1 项）
- **流程修复**：CI 构建的发行版此前为空说明；NSIS 构建中文文件名崩溃；发行说明现随版本自动写入
