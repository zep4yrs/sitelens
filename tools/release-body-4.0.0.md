# SiteLens v4.0.0 — 攻击链还原

![SiteLens 4.0.0 扫描工作台](../../assets/release-4.0.0.png)

发布日期：2026-09-18 ｜ 上个版本：[v3.0.0](../../releases/tag/v3.0.0) ｜ GPL-3.0

4.0 做了三件事。

**让软件轻下来。** 用惰性解码、GC 软上限、扫描结束归还内存等手段治理资源占用。本机实测：引擎空闲内存从约 977MB 降到约 129MB，全量扫描峰值从约 934MB 压到约 796MB（单机实测口径，见「实测数据」）。

**让报告连起来。** 新增事实图：把一次扫描收集到的入口点、各类命中、证据与影响，组织为带统一标识的结构化图谱，并在「攻击链」页给出关联视图。它做的是**证据关联**——每条关联边都必须有真实证据支撑，没有证据的一律不建；它**不做自动攻击路径推理**。

**让界面换过来。** 工作台整体重排，源码审计升级为带文件树与代码预览的审计工作台，暗色模式改为中性黑（此前偏蓝）。

从 3.0 桌面版升级：设置 → 检查更新，或下载安装包覆盖安装。配置、扫描历史与模板池沿用原有目录和格式，覆盖安装即可继承。

## 升级前必读

- **无需迁移操作**：`.sitelens.yml` 配置、扫描历史 `data/state/`、模板池与情报库沿用 3.0 的目录与格式；覆盖安装即继承，卸载向导默认保留数据（静默安装 /S 同样默认保留）
- 事实图**默认不勾选**（界面「事实图」芯片默认未选，配置 `scan.graph` 默认 false）；不勾选时扫描行为与 3.0 一致，勾选后随扫描收集结构化证据，扫描时长可能略有增加
- 自动更新源现在只有 GitHub（CNB 更新通道已下线）。网络慢可直接用安装包手动覆盖，效果相同
- 安装包未做代码签名：Windows 首次运行若弹 SmartScreen，点「更多信息」→「仍要运行」

## 新能力

**事实图与攻击链视图（证据关联）**

扫描时勾选「事实图」后，引擎随扫描把入口点（URL 与参数）、各类命中（检查规则 / Nuclei 模板 / 被动指纹 / 参数注入 / JS 分析）、证据与影响收为带稳定标识的图实体。建链只做三类有据关联：入口点到落在该入口上的发现、已证明漏洞到其影响、以及黑白盒关联与权限变化；**每条边必须引用真实证据（derived_from 非空），无证据的候选边一律不建**——宁缺不造。扫完在「攻击链」页查看关联视图，可导出 JSONL（schema 见仓库 `docs/schema-graph-v1.md`，供后续分析工具直接读取）。3.0 的验证回归命令 `sitelens regression` 行为不变。

需要说明边界：这是**证据关联，不是攻击路径推理**——它不会替你判断"攻击者一定能走到哪"，只把真实共现的事实按证据连起来，判断留给看报告的人。黑白盒关联（把源码审计的数据流与黑盒命中按参数名/路径/技术对上）通过命令行提供：`sitelens audit -graph` 产出白盒事实、`sitelens correlate` 关联两份结果（自动关联最高标 probable，不自动标 confirmed）；工作台里的源码审计结果目前独立展示，未并入事实图。

**源码审计工作台**

基于 3.0 已有的源码静态审计能力（16 条规则 + 可选的 AST 污点分析，引擎侧未另起炉灶），把界面升级为完整的审计台：选一个文件夹或直接拖入，左侧可折叠文件树，点开文件右侧显示代码，**有命中的行按严重度标红/标黄**，发现列表点一条跳到对应行居中高亮。取消了 512KB 的预览上限（二进制文件除外）。上传文件在临时目录中审计、用毕即清，服务端不留存。

**内存治理**

情报库从"启动即全量解码进内存"改为按需解码，配合 GC 软上限（1GiB）与扫描结束归还内存、驻留记录上限裁剪。以下为本机（Windows 11）实测：空闲约 977MB → 约 129MB；DVWA 全量扫描场景峰值约 934MB → 约 796MB。代价是垃圾回收更积极，同机开关治理各跑五轮的对照实测中，扫描时长差异在误差范围内（13.90s 对 13.98s）。

**全新工作台**

主动功能（综合扫描 / 网络层检测 / 登录爆破 / 源码审计 / 批量扫描）收进左侧控制栏，画布归结果；被动页（设置 / 情报库 / 历史 / 攻击链）与工作台共用同一套侧栏。全部页面站内切换，不再整页刷新。

## Bug 修复

按你可能遇到的症状分组，以下问题均已修复并回归验证：

**登录爆破**
- 选「无验证码」跑完显示"未命中"——此前所有尝试在内部被验证码流程跳过，从未真正提交
- 明明试出了弱口令，结果页却显示"未命中"——命中结果在最后一步被丢弃
- 每跑一次任务，后台多一个每秒一次的隐藏轮询

**源码审计**
- 文件夹里嵌套子目录的文件点不开
- 有漏洞的代码行不标红标黄
- 大于 512KB 的文件打不开（现取消该上限）
- 文件夹上传首次偶发失败

**界面**
- 暗色模式的黑偏蓝
- 窗口拖窄时左侧功能按钮挤压变形
- 七处冗余说明文字清理

## 如何启用事实图

扫描页「验证」组勾选「事实图」，扫完到「攻击链」页查看，可导出 JSONL。利用级验证开关位置不变（设置 → 引擎配置），3.0 开启过的升级后保持原状。
