# SiteLens v4.0.1 — 修复版

发布日期：2026-09-20 ｜ 上个版本：[v4.0.0](../../releases/tag/v4.0.0) ｜ GPL-3.0

这是一个纯修复版本：修了 20 个问题，没有新功能，不需要任何迁移操作。
4.0.0 的桌面版用户会直接收到自动更新提示，点一下就能升上来。

这些修复来自一次完整的代码核查（四路评审 + 逐项确认后才动手），
每一项都有对应的测试验证。下面按「你可能遇到的现象」分组说清楚。

## 升级前必读

- **无需任何操作**：配置、历史记录、模板池全部兼容，装完直接用。
- **自动更新**：4.0.0 桌面版会收到更新提示（更新源在 GitHub），
  也可以手动下载本页安装包覆盖安装，两种方式效果一样。
- **安装包未签名**：首次运行时 SmartScreen 可能拦一下，选「更多信息 → 仍要运行」。
  签名需要购买证书，目前没有。

## 这次修了什么

### 页面没反应、按钮点一次就坏

- 攻击链页**第一次打开是空白的**，要先点一下下拉框才出内容，刷新按钮也失灵——
  现在打开页面就会加载，刷新按钮正常。
- 批量扫描的**取消按钮用过一次就再也点不动**——现在每轮自动复位。
- 如果你设置过 API Token，会发现**审计上传、攻击链页、删除历史、导出按钮全部报 401**
  （它们没带鉴权头）——现在全部正常。

### 扫描结果缺东西

- 审计上传的闸门放大到了 8MB，但扫描内部还停在 512KB——
  结果就是 0.5MB 到 8MB 之间的源码**显示「已扫描」，实际一条发现都不会有**。
  现在两层上限对齐了。
- 扫描时**带参数的链接和表单从来没有进入过入口点收集**，攻击链的入口视角缺一块——
  现在正常收集。
- SSRF 检测命中时会在事实图里放一个**没有任何证据支撑的节点**，
  破坏了「有节点必有证据」的规则——不再产出这种节点。
- 内存吃紧时引擎应该降低模板量运行，但**这个降档实际是个空操作**——现在真正生效。

### 磁盘悄悄变大、状态灯骗人

- 历史记录淘汰、清空全部历史时，**对应的扫描图目录没有跟着删除**，
  磁盘会慢慢堆积——两条路径现在都会清理。
- 设置页的 OSV 漏洞库同步**失败了也显示「同步完成」的绿灯**——现在如实显示失败。
- 设置页有一个**每 1.5 秒一次的轮询，关不掉、永不停止**——修了。

### 登录爆破停不下来

- 扫描页面点**取消没有反应**，只能干等它跑完——现在取消即时生效。

### 桌面版稳定性

- 桌面版退出时，**引擎进程可能残留在后台**——现在连同子进程一并清理。
- 引擎配置文件如果损坏，旧版本会**把你全部的引擎配置清空后重写**——
  现在保底处理，不再静默清空。
- Wails 实验壳的主窗口存在并发竞争（托盘「显示主界面」在冷启动期点了没反应）——加锁修复。
- 拖整个文件夹进审计时，文件树会出现**双层同名目录**——修了。
- 黑白盒关联的结果此前**进不了攻击链视图**（关联边建不出来）——修了。

## 已知问题（这版没修，如实告诉你）

- 修改设置与正在跑的扫描**同时发生**时，对配置对象的读写存在竞争。
  影响很小但确实存在，因为改动面大，单独排期处理，不混在修复版里。
- 配置了多个更新源时，手动下载的「源选择」逻辑有小瑕疵
  （默认单源场景无实际影响）。
- Wails 实验壳的启动页时长从进程启动算起，非常慢的机器上开场动画可能被掐短。

## 验证

- 全量测试通过：引擎全部 Go 包测试 + 前端单元测试 + Wails 壳测试，格式门禁干净。
- 代码三端同步：github / cnb / gitee 同一提交。

- 想回滚：v4.0.0 与 v3.0.0 的安装包仍保留在 GitHub 更新源的资产里，覆盖安装即可。
