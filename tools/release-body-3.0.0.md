# SiteLens v3.0.0 发布说明

发布日期：2026-09-12 ｜ 上一版本：v2.0.0 ｜ 许可证：GPL-3.0

这个版本我们做了挺久，最大的变化是扫描覆盖面终于提上来了——模板池从 5,400 多条变成 117,889 条，而且这次是全量跑，不再是抽样子集。代价说实话也有：全量模式下扫描时间会明显变长，所以我们保留了强度分层，日常巡检用「标准」就行，别一上来就 full。

另一个大变化是影响证明。以前扫描完，你拿到的是"这里可能有问题"；现在如果目标在你的授权白名单里，并且你打开了利用级验证，SiteLens 会往前多走一步——用四种无害的方式（回显、报错、时延、出带）去证明"这个洞真的能被利用"，最后给一个结论：proven 是确实能利用，observed 是看到了可利用面但没完全证明，none 是没发现。给客户交付的时候，这种证据比"疑似"硬得多。

要提醒的是：利用级验证默认是关的，而且只对配置里白名单内的目标生效。没配置白名单，这个功能一层请求都不会发——我们用测试把这个行为固化了，不是写在文档里的口头承诺。

## 数据方面

这次把数据来源全面换成了公开渠道：afrog、xray、nmap、微软公告、CISA、NVD，随仓库开源分发。数字直接给你：

- 可运行模板 117,889 条（官方 http + 协议族 + afrog + Wordfence + linuxadi 40k 等，统一漏斗准入）
- 指纹库 13,727 条（自建精编 372 + webappanalyzer 社区 2,377 + EHole 中文产品 10,978）
- 漏洞情报 31,539 条（精选 1,985 + 模板情报行 29,554，覆盖 10,289 个产品）
- NVD 字典 371,755 条（update-nvd 全量镜像，约 50 分钟，建议低峰跑）
- KEV 在野利用 1,709 条，24 小时自动更新

模板情报行是新东西，值得多说一句：以前情报关联告诉你"这个组件可能有洞"，现在会顺带告诉你"池子里有哪几条模板能实际验证它"，报告里直接附上模板路径。给客户写报告的时候这条链路很省事。

指纹匹配也重做了底层：13,727 条规则实测 24.2ms/页（40KB 页面），规则数涨了 37 倍但速度没有崩，靠的是字面量前缀桶预筛——一条 grep 一遍过，不再逐条扫。

## 非 HTTP 协议检测

以前 SiteLens 只会说 HTTP。现在有了原始拨号层，可以直接对 tcp / dns / ssl 目标发探测、收响应做匹配，内置 214 条协议模板（Redis、FTP、SSH、VNC、MySQL、SMTP 这类服务的 banner 级探测，外加官方 network/dns/ssl 目录）。端口服务探测发现目标开了哪些端口后，会自动把协议模板路由过去，不需要你手工指定。

## 修了几个比较烦的问题

- 有些排除式模板会被错误调度，空转浪费扫描时间，修了
- 首次扫描偶尔会卡在索引重建上不动，修了
- 一条不兼容的社区指纹会让整个扫描进程退出，修了（现在跳过坏模式，不影响其他）
- NVD 镜像这种长任务以前一直静默，现在有按页的进度输出

性能上顺带做了个大优化：13,727 条指纹规则下单页匹配从 413ms 降到 24.2ms（中间还经历了一版 70ms 的实现，后来换前缀桶才压下来的），bench 固化在仓库里，欢迎自己跑。

## 已知问题和还在弄的

- 反序列化检测目前只是入口面信号（低危），不是漏洞级确认，我们还在做
- 协议检测是第一版：UDP 只做了单轮收发，没有会话跟踪；ssl 客户端基线卡在 TLS 1.2，旧协议探测后面会加显式开关
- EHole 社区指纹是置信度分层的（conf 70），准确率不如精编规则，介意的话可以删掉对应条目
- `-race` 竞态检测本机 Windows 跑不了（需要 cgo），这项门禁由 CI 执行
- 全量模板模式下扫描时间会比较长，靶场实测 DVWA 认证扫描跑了约 23 分钟——如果你只是日常巡检，请用「标准」强度，别硬上

## 升级与兼容

`.sitelens.yml` 和 `data/state/` 完全兼容，覆盖安装、旧数据直接用。回滚也简单：换回 v2.0.0 的二进制就行，数据不用动。

新增配置只有一段（不写就是默认关）：

```yaml
exploit:
  enabled: true
  authorized:            # 只写你有权测试的目标；*.domain 仅匹配子域
    - "lab.example.com"
    - "*.client-lab.cn"
```

开起来之后，扫描页会多一个「利用级验证」的勾选，命中后结果页多出影响证明的徽章和证据。

具体迁移步骤（lite 版补数据、NVD 首次拉取、验证清单）写在 [升级指南](docs/upgrade-3.0.md) 里，这里不重复。

## 下载哪个

- Windows 常规使用：`setup-full.exe`（推荐，模板池和情报都内置）
- 先试用、磁盘紧张：`setup-lite.exe`，之后用 update-* 在线补
- 免安装：`full-win64.zip`
- Linux amd64：`linux-amd64.zip`
- 做流水线集成：`intel_dump.json.gz`、`nuclei-templates.tar.gz`、`tpl_intel.json.gz`

内存建议 8GB 起（全量模板池扫描吃内存），磁盘 full 版 1GB 左右。SHA256 校验和由 CI 构建后补在本 Release。
