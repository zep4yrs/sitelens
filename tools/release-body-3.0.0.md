# SiteLens v3.0.0 发布说明（利用器 · 影响证明版）

**发布日期**：2026-09-12 ｜ **上一版本**：v2.0.0 ｜ **许可证**：GPL-3.0

**一句话摘要**：扫描覆盖面提升约 22 倍（可运行模板 5,400+ → 117,889，全量执行），新增非 HTTP 协议检测与四通道影响证明；利用级能力默认关闭，仅限显式授权目标启用。

---

## 一、重要变更（升级前先读）

1. **数据来源全面公开化**：情报库不再包含任何商业来源数据，全部为公开来源（afrog / xray / nmap / 微软公告 / CISA / NVD），并随本仓库开源分发。v2 用户升级无需操作，覆盖面由公开数据与模板情报行顶替。
2. **模板默认全量执行**：升级后扫描调度全池 117,889 条模板（此前为子集采样），扫描时长会增加；如需控制时长，选择「快速 / 标准」强度即可。
3. **利用级验证默认关闭**：必须显式开启并配置授权白名单才会发出探针；未配置时行为与 2.0 完全一致。

## 二、你能多做什么（新能力）

| 你可以 | 具体能力 |
|---|---|
| **向客户证明漏洞真实可利用**，不再只是告警 | 利用级无害验证四通道：回显唯一标记、数据库指纹、时延差、出带回连；结论分 proven（影响已证明）/ observed（观测到可利用面）/ none |
| **检测非 HTTP 服务**（214 条协议模板：Redis / FTP / SSH / VNC / MySQL / SMTP 等） | 原始拨号层直连 tcp/dns/ssl，端口服务探测自动路由 |
| **一键复测漏洞是否修复**（交付验收、整改回归） | `sitelens regression <scan_id>`，输出 仍在 / 已修复 统计，退出码直接接 CI |
| **降低误打未授权目标的法律风险** | 利用级三重闸：请求开关 × 配置总闸（默认关）× 目标白名单；**未授权目标零请求**（单测固化断言） |

## 三、改进与优化

- 指纹匹配 **24.2ms/页**（13,727 条规则），较上版快约 17 倍；新增中文产品指纹 10,978 条
- NVD 字典 **371,755 条**接入：漏洞关联自动补 CVSS 评分、支持 CPE 检索
- 漏洞情报 **31,539 条**：新增模板情报行 29,554 条（指纹命中直接给出「可跑模板」）
- 六扫描并行执行；扫描热路径不再触发索引重建（首扫超时修复）

## 四、修复

- 更准：排除式模板不再被错误调度空转
- 不再卡住：首次扫描不会因索引重建而停滞
- 不再中断：单条不兼容社区指纹不再导致整个扫描退出
- 有进度：NVD 镜像等长任务按页输出进度，不再静默

## 五、兼容性与升级

- `.sitelens.yml`、`data/state/`（历史与调度）**完全兼容**，v2 数据直接可用，覆盖安装即可
- 旧版 `intel_dump.json.gz` 建议升级后重新生成（新版为纯公开来源数据）
- API 仅新增（`GET /api/replay/{id}`、verified 条目新增 impact 字段），无破坏性变更
- 回滚：换回 v2.0.0 二进制即可，数据无需迁移
- 详细步骤见 **升级指南**（docs/upgrade-3.0.md）

## 六、如何启用利用级验证（三步）

1. `.sitelens.yml` 添加：

```yaml
exploit:
  enabled: true
  authorized:            # 只写你有权测试的目标；*.domain 仅匹配子域
    - "lab.example.com"
    - "*.client-lab.cn"
```

2. 扫描页勾选「利用级验证」（或 API 传 `exploit: true`）
3. 命中后结果页显示 影响已证明 / 可利用面观测 徽章与证据

不配置或目标不在白名单：利用级探针**零请求**，其余功能不受影响。

## 七、已知问题与限制

- 反序列化检测为入口面信号（低危），不是漏洞级确认
- 协议检测 v1：UDP 单轮收发，无会话跟踪；ssl 客户端基线 TLS 1.2
- NVD 全量镜像约 50 分钟（无 API key），建议低峰期执行
- EHole 社区指纹为置信度分层（conf 70），准确率低于精编规则
- `-race` 竞态门禁由 CI 执行（Windows 本机需 cgo）
- 全量模板模式下扫描时长增加，按强度分层控制
