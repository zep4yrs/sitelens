# SiteLens i18n 规范（5.2.x / FE-07）

> **目标**：中文（zh-CN）为源语言、英文（en-US）为第一目标语言；语言切换在 WebView2
> 内即时生效，字典可校验、可增量扩展；**扫描内容与证据不翻译**，只翻译界面壳。
>
> - **现状快照（2026-11-01，工作区含并行未提交增量）**：字典与 `t()`/`apply()` 已抽到
>   **`web/js/i18n.js`（UMD，zh-CN/en-US 各 54 键、键集合对称）**，`common.js` 已接入
>   「按需加载 + 壳/模式行用 `t()`」；但**页面静态文案尚未标注 `data-i18n`**、`<html lang>`
>   仍未跟随切换、`document.title` 未翻译。本文同时定义「现状」与「目标结构」，标 ⏳ 的是
>   FE-07 待实现/待验收项。工作区仍在变动，**以 Lead 合入后的代码为准**。
> - **事实来源**：`web/js/i18n.js`、`web/js/common.js`、`web/settings.html`、`web/*.html`。与代码冲突时以代码为准。
> - 关联：[设计系统与组件契约](设计系统与组件契约-5.2.md)（组件文案与 a11y）、
>   [新功能路线图](新功能路线图-5.2.md)（FE-07 进度）。

## 1. 语言与范围

| 项 | 约定 |
|---|---|
| 源语言 | `zh-CN`（简体中文）。**键值即中文**，不需要单独的中文库文件 |
| 目标语言 | `en-US`（首个双语目标）；其他语言按 §5 流程增量接入 |
| 翻译范围 | 界面壳文案：导航、模式行、页面标题、按钮、表单标签/提示、表格表头、空/加载/错误态、toast、设置页各节、反馈页、API 文档页说明 |
| **不翻译** | 目标 URL、域名、技术/产品名、CVE/CWE 编号、模板名、check id、证据链里的请求/响应/载荷、扫描结果数据、导出文件内容；严重度/来源等枚举用**映射表**而非机器翻译 |
| 明确不在本批 | Go 侧生成的报告（HTML/CSV/Markdown/SARIF message，`internal/server/report.go`）、API 错误文案、桌面壳（splash/托盘/更新对话框）、TUI/CLI 产品线——它们需要服务端 locale 参数或独立字典，列入 §6 已知缺口 |

### 3.1 文件与加载

| `web/<page>.html` | ⏳ 待改造 | 静态文案需加 `data-i18n` / `data-i18n-aria-label` / `data-i18n-title` / `data-i18n-placeholder`；本轮 html 未改 |

### 3.2 字典结构（现行约定）

```js
// web/js/i18n.js —— UMD；zh-CN 为源语言（键值即中文），en-US 必须全量且键集合对称
var DICTS = {
  "zh-CN": { nav_history: "历史", mode_scan: "综合扫描", theme_toggle: "切换明暗主题", /* … */ },
  "en-US": { nav_history: "History", mode_scan: "Scan", theme_toggle: "Toggle light/dark theme", /* … */ }
};
```

| 规则 | 说明 |
|---|---|
| 键命名 | **扁平「域_语义」小写蛇形**（现行）：`nav_*` / `mode_*` / `a11y_*` / `btn_*` / `keys_*` / `<field>_label`。若后续改为点分命名（如 `nav.history`），需一次性迁移 + 兼容映射，不得两套并存 |
| 源语言 | `zh-CN` 必填全量；任何语言的缺键回退 `zh-CN`，**绝不把键名展示给终端用户**（`t()` 返回 `null`，调用方回退中文字面量） |
| 插值 ⏳ | 现行 `t(key[, fallback])` **不支持参数插值**；需要 `{name}`/`{count}` 时先扩展 API（并补测试），禁止调用方手工字符串拼接 |
| 富文本 | 禁止在文案里内嵌 HTML；需要强调时拆键或由调用方包元素 |
| 新增键 | 先加 `zh-CN` 再补 `en-US`；两语言键集合必须对称（门禁断言） |

### 3.3 取词与应用（现行 API）

```js
// t(key[, fallback])：当前语言 → zh-CN → fallback → null
// apply(root)：扫描并替换 [data-i18n] / [data-i18n-aria-label] / [data-i18n-title] / [data-i18n-placeholder]
// setLang(lang) / getLang() / normalize(lang)
```

- **静态文案**：`<button data-i18n="btn_start_scan">开始扫描</button>`；`apply()` 用
  `textContent` 写入（天然防 XSS）。
- **属性文案**：`data-i18n-title="keys_btn"`、`data-i18n-aria-label="a11y_main_nav"`、
  `data-i18n-placeholder="url_label"`，逐属性写入。
- **动态文案**：JS 里 `t("btn_export_json") || "JSON"`，结果经既有 `esc()` 后再入 HTML。
- **Turbo 换页**：`common.js` 在壳重建/偏好变更处调用 `apply(document)`；一次性区只注册一次
  全局监听（沿用 `window.__slCommonLoaded` 模式）。
- **降级**：`/js/i18n.js` 加载失败时 `common.js` 用最小回退字典（顶栏英文）保证不闪空，功能不受影响。

### 3.4 语言切换（现状与目标）

```
现状：settings 切换 → slPrefs.set({lang}) → common.js setLang + apply（壳即时变）
                    → settings.html 仍 location.reload()（页面静态文案不会变，因为未标注）
目标：setLang(lang) → 校验 → 存偏好 → document.documentElement.lang = lang   // ⛔ 现状缺这一步
                    → apply(document) → 派发 sitelens:langchange → 不整页 reload
```

- **过渡策略**：FE-07 第一批允许保留 `location.reload()`（现状），但**必须**同时修正
  `document.documentElement.lang`（a11y 缺陷）；页面静态文案完成 `data-i18n` 标注后再去掉 reload。
- 不翻译的内容（URL/证据/请求响应）不因切换而重绘；**只重绘界面壳**。
- 语言偏好随「皮肤配置导入导出」迁移（已有四字段 JSON，无需新增格式）。

### 3.5 与设计系统/组件的关系

- toast、空态、错误态、按钮禁用原因等**文案模板**集中在字典；组件只负责结构（见
  [设计系统与组件契约](设计系统与组件契约-5.2.md) §4/§5）。
- 严重度/来源徽章：中文由服务端 `severity_zh` 提供，英文由前端映射表 `sev.*` 提供
  （`sevBadge(sev)` 不再依赖中文入参）；两处口径必须一致，否则同一页面中英混排。
- 语言切换按钮本身遵守 a11y：`aria-pressed`/`role=radiogroup` ⏳（随 FE-04）。

## 4. 文案规范

### 4.1 术语表（中 → 英，强制统一）

| 中文 | 英文 | 备注 |
|---|---|---|
| 扫描 | Scan | 动词/名词同形 |
| 发现 / 命中 | Finding / Hit | 发现=finding（结果实体）；命中=hit（判定动作） |
| 已验证 | Verified | 历史页页签名 |
| 证据链 | Evidence chain | 不拆成 evidence + chain |
| 覆盖度 / 覆盖率 | Coverage | 结果页卡名用「扫描覆盖度」 |
| 预检 | Preflight | `scan.preflight` 配置同名 |
| 指纹 | Fingerprint | |
| 情报 / 情报库 | Intel / Intel library | 不用 intelligence |
| 模板 | Template | |
| 批量 | Batch | |
| 定时任务 | Schedule / Scheduled task | |
| 白名单 | Allowlist | 不用 whitelist（新文案统一 allowlist） |
| 护栏 | Guardrail | 安全护栏 |
| 源码审计 | Code audit | |
| 登录爆破 | Credential testing | 界面避免 "brute force" 字面（合规口径） |
| 利用验证 | Exploit validation | |
| 攻击链 | Attack chain | |
| 事实图 | Evidence graph | 不译成 fact graph |
| 严重度 | Severity | 值：Critical/High/Medium/Low/Info |

| 目标 | Target | |
| 导出 | Export | |
| 诊断包 | Diagnostic bundle | 反馈页 |

### 4.2 语气与格式

- 中文：陈述句、动词开头按钮（保存/开始扫描/取消/导出）；不用感叹号与营销腔。
- 英文：**sentence case**（仅首词与专名大写）；按钮用动词原形（Save / Start scan / Cancel / Export）。
- 标点：中文全角（，。：）；英文半角 + 空格；数字千分位；日期 `2026-11-01`；时长「2.6 秒 / 2.6 s」。
- 错误文案三段式：**现象 + 原因 + 下一步**（例："无法连接引擎服务（可能已退出）→ 请确认
  `sitelens serve` 在运行 → 重试"）；英文同结构。
- 长度约束：英文允许比中文宽 ≤1.6 倍；按钮/页签文案不超过 24 字符（en）/12 汉字（zh），
  超长走两行或 tooltip；375px 宽不得溢出（FE-11 验收）。
- 变量占位符必须出现在两种语言里且顺序可不同（用命名占位符，禁止 `%s` 位置参数）。
- 安全：任何插值内容都必须经 `esc()` / `textContent`；不在可翻译模板里拼接用户输入形成 HTML。

## 5. 新增语言流程

| 步骤 | 动作 | 门禁 |
|---|---|---|
| 1 | 复制 `zh-CN` 全量键 → 新语种（`ja-JP` 等），先**全量翻译**，禁止缺键合入 | `i18n.test.mjs` 键集合一致 |
| 2 | 插值占位符与中文完全一致；空值/纯空格视为缺失 | 同上 |
| 3 | 长文本 smoke：目标语言膨胀系数 1.5×（德语/俄语约 1.3–1.5×），375px 宽无横向滚动 | 人工/截图（FE-11 后自动化） |
| 4 | 字体回退核实：`--font-sans` 链含 LXGW/Noto/系统栈，CJK 之外语言可读 | 目测浅/深两主题 |
| 5 | 在 `settings.html` 语言开关增加选项；`<html lang>` 正确；文档与 README 语言说明同步 | 人工 |
| 6 | 变更记录写入本文 §8 与 CHANGELOG（"新增 xx 语言"） | — |

**回退策略**：任何缺键/空值 → 回退 `zh-CN`；测试环境把缺键视为失败，生产静默回退并可用
`window.slI18N` 在控制台排查。**不允许**上线只翻译一半的语种（宁可不提供该语言）。

## 7. 门禁与验收（FE-07）

### 7.1 门禁（✅ 已接入 CI：`scripts/i18n.test.mjs`）

`web/js/i18n.js` 已是 UMD，`scripts/i18n.test.mjs` 用 `node --test` 断言：

1. **键完整性**：`zh-CN` 与 `en-US` 键集合完全一致；无空值/纯空格；无重复覆盖（**当前 113×2 键对称**）。
2. **插值一致**：同一键的 `{name}` 占位符集合两语言一致（顺序可不同）。
3. **无硬编码中文**：`web/*.html` 与 `web/js/*.js`（白名单：注释、示例数据、协议正文、
   monaco/turbo/jszip）不得出现未挂 `data-i18n` 的中文文本节点；白名单显式维护。
4. **`<html lang>` 一致性**：切换语言后语言属性更新（无头 smoke 断言）。
5. **应用面**：`apply(root)` 对 `data-i18n*` 标注的替换计数可断言（含缺键不覆盖原文本）。

命令并入 `.cnb.yml`「前端转义回归」步骤：
`node --test scripts/i18n.test.mjs`。
