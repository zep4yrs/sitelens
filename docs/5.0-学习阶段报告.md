**关键血缘（可关联率实证）**：
- CVE 跨源交集：NVD∩模板 38,628；tpl_intel 的 29,554 CVE **全部** ⊂ NVD 且 ⊂ 模板

- **Template↔Check 钥匙**：模板文件 `id:` 字段实扫，verified 行 `check_id = "nuclei-"+yaml_id` 可精确联接

## 二、数据分类结论

| 类别 | 数据 |
|---|---|
| supervised data | NVD 291,484 条带严重度 CVE（label=base severity，confidence=high） |
| weakly supervised data | NVD CPE 产品约束→CVE↔产品关系边（confidence=medium）；tpl_intel 模板×产品（confidence=medium） |
| static knowledge | KEV/service_fp/technologies/affected_ranges/tech_cpe（仅 3 条映射） |
| feature source | 描述文本（TF-IDF）、年份、产品数、模板 tags/来源 |
| ranking signal | 历史 216 条 nuclei 命中（confidence=low，正例少）；nuclei_schedule lastrun（本轮为空） |
| unlabeled data | 80,271 条无严重度 CVE、58,404 个无 CVE 模板、11,966 服务指纹 |

**未命中/未执行/缺失一律不作为 negative**——该纪律在本阶段继续保持。

## 三、实验与真实结果

### EXP-1001：CVE 严重度学习（supervised，规模最大）
- 训练/测试：148,356 / 143,083（时间切分：train pub<2024，test≥2024）
- LR(SGD)+TF-IDF：**accuracy 0.574 / macro-F1 0.484**；AUC-ovr：critical **0.827**、low 0.774、medium 0.758、high 0.697
- 消融：仅元数据（HistGB）accuracy 0.473 / F1 0.212 → **文本承载主要信号**（+10pp/acc，+27pp/F1）
- 跨源验证：vuln_kb CVSS 分带一致率 **81.2%**（474 行）；cve_ms 一致率 36.6%（17,204 行——微软公告严重度语义与 NVD 不同，属真实发现）
- 稳定性：seed 1 vs 777 → acc 差 0.0028 / F1 差 0.0028（**稳定**）

### EXP-1002：CVE→产品/技术 关系预测（weak relation，头条结果）
- 200 个高频产品类；训练边 1,066,892；测试 CVE 31,130（时间切分同上）
- **P@5 = 0.9085 / P@10 = 0.9425 / MRR = 0.864**（随机 P@5=0.025 → **36 倍**）
- 含义：对一个**全新 CVE**，仅凭描述文本即可给出受影响产品/技术 Top-5，91% 命中——5.0 从此具备"新 CVE 先验关联技术"的知识能力
- 与 SiteLens 技术宇宙交集：Top-200 类中 35 个直接对应技术名（经 tech_cpe/name 归一）

### EXP-1003：模板命中先验（ranking signal，来自真实扫描历史）
- 216 条历史 nuclei 命中 → yaml id → 90 个模板（47 唯一 id；语料命中率 0.0763%）
- **lift 实证：info 级模板 12.05 倍**（暴露面检测是真实命中的主体）；community-40k 源 3.14 倍；**wordfence 源 82,709 条模板命中为 0**
- 价值：引擎当前"severity 排序"与真实命中严重背离（与 EXP 前一轮 check 级发现互相印证），模板调度应引入 source/暴露面先验

## 四、回答目标十问

1. **10 万级数据是什么**：公开安全知识语料（NVD CVE 全量、117,889 社区+官方模板、微软公告、KEV、指纹库）+ 引擎自产索引/情报行；不是"扫描结果"，是知识与规则宇宙
2. **哪些真正被模型学习**：NVD 291k 有标签 CVE（文本→严重度）、NVD CPE 边 1.07M（文本→产品关系）、216 条历史命中（模板先验特征）
3. **哪些只是知识库**：KEV/service_fp/technologies/affected_ranges——本轮仅作特征/知识引用
4. **产生了多少训练样本**：EXP-1001 训练 148,356；EXP-1002 训练边 1,066,892（200 类）；EXP-1003 为先验表（90 命中模板）
5. **产生了什么标签**：supervised=严重度四类（high confidence）；weak relation=CVE↔产品（medium）；ranking signal=模板命中（low）
6. **模型学到哪些安全关系**：描述→严重度（critical AUC 0.827）；描述→受影响产品（P@5 0.909）；模板来源/级别→命中概率（info 12×）
7. **哪些 Feature 最有效**：EXP-1001 描述 TF-IDF（消融实证）；EXP-1002 同；EXP-1003 source∈community-40k、sev=info、cms_linked
8. **是否泛化**：时间泛化（train<2024→test≥2024）成立；跨源泛化对 CVSS 分带 81%、对微软公告仅 36.6%（语义差异，如实）；host 维度不适用（知识学习与 host 无关，天然免疫 host 泄漏）
9. **哪些任务仍缺数据**：CVE↔CWE（主仓库无 CWE 字段）；exploit 判定（0 样本）；模板执行的负样本（仍无执行日志）；tech_cpe 仅 3 条映射
10. **下一步最该采集**：① update-nvd 投影补 CWE 字段（数据包工程）；② 引擎验证面执行日志（解锁 T1/T2 负样本）；③ 授权靶场重放/L2 标签；④ 扫描历史里记录模板选择集合
