# SiteLens 5.3.2 发行说明

> 桌面版自动更新修复版：5.2.3 / 5.3.0 / 5.3.1 的自动更新因 Windows 提权限制无法启动安装器，
> 本版修复并默认开启自动安装。

## 版本摘要

- **自动更新修复（根因）**：安装器是 admin 清单，非提权壳进程直接 CreateProcess 会被
  Windows 拒绝（ERROR_ELEVATION_REQUIRED 740），安装器从未启动；
- 改用 ShellExecute 语义拉起安装器（`cmd /c start`），由系统弹 UAC，确认后完成覆盖安装；
- 安装器静默更新前先结束旧壳/引擎并等待解锁，装完（文件+注册表落盘后）再拉起新版本；
- 启动检查默认自动安装：启动 8s 后检查 + 每 6 小时复查，自动下载 → sha512 校验 →
  静默安装（一次 UAC）→ 重启；设置页「桌面端」可关闭自动更新；
- 设置页「检查更新」按钮现在触发完整流程（检查→确认→下载→安装），不再只是提示。

> **一次性说明**：已安装的 5.2.3 / 5.3.0 / 5.3.1 旧壳内仍是旧更新器（无法自更新到 5.3.2），
> 请手动安装一次 5.3.2；从 5.3.2 起自动更新生效。

## 升级说明

- 5.2.3+ 覆盖安装，配置/历史/种子数据兼容；
- 自动更新需要一次 UAC 确认（机器级安装到 Program Files 的固有约束，非零交互）；
- 不想自动安装：设置 → 桌面端 → 关闭「自动更新」，之后只提示。
