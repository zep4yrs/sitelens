# SiteLens 产品说明与版本区别（v5.2.0）

## 产品简介

SiteLens 站点透视是一款**验证型 Web 安全评估工具**：指纹识别 → 漏洞情报
关联（三级判定）→ 无害化验证 → 影响证明 → 可回归报告；单二进制引擎交付，
引擎侧零外部运行时依赖（前端零构建，网页外壳字体走公共 CDN、不可达时回退
系统字体栈，不影响扫描能力）。

核心能力：

- **指纹识别**：header / cookie / meta / body / script / icon_hash 六通道 +
  13,727 条规则（自建精编 372 + webappanalyzer 社区 2,377 + EHole 中文
  产品 10,978），字面量前缀桶预筛（实测 24.2ms/页 @40KB）
- **模板验证**：可运行模板 **117,889 条**（官方 http+协议族 / afrog /
  Wordfence / linuxadi 40k 等，统一漏斗准入），MoE 三路调度全池轮转
- **非 HTTP 协议检测（3.0）**：tcp / dns / ssl 模板 214 条经原始拨号层
  （netx）执行，端口服务探测自动路由，安全闸全程校验
- **漏洞情报**：31,541 条关联情报（精选 1,985 + 模板情报行 29,556）+
  NVD 字典 371,755 条（评分补全 / CPE 检索）+ OSV 区间补全 + KEV 在野
  利用红标 + CVSS 本地计分
- **利用级无害验证（3.0）**：回显 / 报错指纹 / 时延差 / 出带四通道影响
  证明，判定 none / observed / proven；授权三重闸默认关，未授权目标零请求
- **验证回归（3.0）**：`sitelens regression` 按原 payload 重放历史发现，
  present / gone / unsupported 三分，退出码表达回归
- **验证引擎**：42 条内置无害验证 + 二次确认 + 回显剔除 + 软 404 基线
- **主动模块**（默认关，授权目标专用）：目录探测 / 子域名枚举 / 接管探测 /
  WebShell 路径 / 端口服务 / FingerDir / 登录爆破
- **DAST**：反射 XSS / 报错 SQLi / 开放重定向 / 目录遍历 / 时间盲注 +
  布尔差分盲注 + SSRF 出带回调 + 反序列化入口面，全部带复现命令证据链
- **事实图与攻击链（4.0）**：扫描产出结构化事实图（10 类实体 / JSONL 契约），
  支持黑白盒关联（`evidence_link`）与**证据驱动的攻击链**（`entry` / `exploit` /
  `recon` / `impact` / `priv` 五类节点；`sequence` 边只认「入口点 → 发现」的
  `EntryID` 真实因果，无证据不成边）；白盒侧含 AST 数据流污点分析
  （py / js / php / java / go，PHP grammar 第一方自持）
- **ML 推理（5.0，默认开；5.2 阶段 1/2 起查表优先、模型兜底）**：严重度先验默认
  「NVD/情报行查表 → `sev-linear` 0.7MB 线性回归兜底」（同一 600 抽样对照：查表
  误差 0、线性 MAE 1.189 vs sev-prior 1.08，+0.11 分；ONNX 降为可选高级包）；
  产品先验优先 NVD CPE / 情报行 product（`tech_source=nvd/intel`），CWE 优先
  NVD weaknesses（`cwe_source=nvd`），查不到才用 `cve-tech`/`cwe-type` 线性模型；
  `cve-tech` 产品先验同时用于调整 check 执行顺序 + 核心档位扩展集增量纳入
  （**只增不删**），前置调度改为指纹技术名确定性映射；全部本机推理、资产随仓/
  随包分发，缺失静默跳过——**不改变任何 check 的命中判定、不凭模型直接产生发现**
- **诊断与反馈（5.2）**：应用内反馈页 + **本机**脱敏诊断包（版本 / 平台 /
  资产就位 / 降级能力 / 最近失败），无埋点、无遥测；提交目标由用户自建
  （默认不提交，可一键复制到 Issue）
- **其他**：TLS/DNS 网络层检测、源码审计、JS 攻击面、无头渲染（可选）

## 安装包版本区别

> 交付口径（2026-10）：5.2.0 的正式交付形态是桌面安装器
> `SiteLens-Setup-5.2.0.exe`（Wails 壳 + 引擎二进制 `sitelens-engine`，安装即用）。
> 5.2 起**引擎与 CLI 拆成两个二进制**：桌面安装包只含引擎（serve + update-seed），
> 命令行能力（scan / audit / doctor / history / update 等）经 npm 线
> `@fengqiao666/sitelens-cli`（TUI，唯一命令行入口）独立分发，不随桌面安装包发布。
> 下表的 full / lite 区分是 3.0 期打包口径，仅供了解历史差异。

| | **full 完整版** | **lite 精简版** |
|---|---|---|
| 体积 | ~1GB（zip，含模板池） | ~10MB（zip） |
| sitelens.exe 主程序 | ✅ | ✅ |
| 指纹规则 / 字典 | ✅ | ✅ |
| 漏洞情报库（31,541 条关联情报） | ✅ 内置 | ❌ 需自行放置 `data/intel_dump.json.gz` |
| Nuclei 模板库（117,889 可运行，含协议族） | ✅ 内置 | ❌ 可用 `update-nuclei` 在线拉取 |
| OSV / NVD / KEV 在线同步 | ✅ | ✅ |
| 适用场景 | 开箱即用、离线环境 | 网络/体积受限，或自行维护数据 |

> **数据说明**：`intel_dump.json.gz`（漏洞情报库）与 `tpl_intel.json.gz`
> （模板情报行）随本仓库分发；NVD 字典（37MB）经 `update-nvd` 在线再生。
>
> 安装方式：桌面安装器 `SiteLens-Setup-5.2.0.exe` 提供向导式安装、自动覆盖升级、
> 开始菜单/桌面快捷方式与完整卸载器；启动后由桌面壳内部拉起引擎。

## 使用

1. 安装并启动桌面版（桌面壳内部拉起引擎，默认监听 http://127.0.0.1:5000）
2. 浏览器打开控制台，「设置」页可调整爬取/扫描参数、API Token、触发 OSV 同步；
   另有「反馈」页可生成本机脱敏诊断包
3. 扫描选择器三维合成：范围（Web/子域/端口服务）× 验证（被动/主动/深度
   盲态）× 强度（快速/标准/完整）；「利用级验证」总闸默认关，开启即对授权
   目标生效（授权判断与合规责任由使用者承担，`gov.cn` 目标代码级强制拒绝）
4. 数据更新：桌面版由引擎随包种子在版本变化后自动覆盖更新；npm 线用
   `sitelens update <目标>`（nuclei / afrog / fp / ehole / nvd / osv / tplintel）
5. 回归验证：`sitelens regression <scan_id>`（退出码 0=无回归，1=存在回归；
   npm 线为该命令的唯一入口）

## 已知限制

- 5.1.0 全代码库体检发现的历史缺陷与处置状态见 `docs/bug清单-5.1.0.md`；
  5.2.0 的修复范围与未解决项见 `docs/release-5.2.0/release-body-5.2.0.md`
  的「已知限制」节。
- **无常驻埋点 / 匿名统计 / 崩溃自动上报**（《用户服务协议》承诺）：反馈只能
  由用户主动生成本地诊断包并自行提交，不采集任何使用行为。
- npm 线默认不带漏洞情报库与 ONNX 严重度模型资产（自备数据/资产后启用，
  缺失时静默跳过）；完整能力形态为桌面安装器。
- 模板来源存活率门禁（任一来源通过率为 0 即告警）目前只修了 afrog 一个来源，
  其余来源的通过率基线尚未固化为 CI 门禁。
