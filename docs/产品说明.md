# SiteLens 产品说明与版本区别（v1.0.0）

## 产品简介

SiteLens 站点透视是一款**验证型 Web 安全评估工具**：指纹识别 → 漏洞情报
关联（三级判定）→ 无害化验证 → 结构化报告，单二进制零外部依赖交付。

核心能力：

- **指纹识别**：header / cookie / meta / body / script 五通道 + 370 项精编规则
- **漏洞情报**：11024 条情报（afrog / xray / TscanPlus）+ OSV 区间补全 + KEV 在野利用 + CVSS 评分
- **Nuclei 兼容**：社区模板 YAML 直接装载（status / word / regex / 头匹配 /
  dsl 安全子集），可运行模板 5400+
- **验证引擎**：41 条内置无害验证 + 二次确认 + 回显剔除 + 软 404 基线
- **主动模块**（默认关，授权目标专用）：目录探测 / 子域名枚举 / 接管探测 /
  WebShell 路径 / 端口服务 / FingerDir / 弱口令审计
- **DAST**：反射 XSS / 报错 SQLi / 开放重定向 / 目录遍历 / 时间盲注 +
  GET 表单字段探测（POST 表单走专用通道）
- **其他**：TLS/DNS 网络层检测、登录爆破（验证码 OCR 需 sidecar）、源码审计

## 安装包版本区别

| | **full 完整版** | **lite 精简版** |
|---|---|---|
| 体积 | ~35MB（zip） | ~10MB（zip） |
| sitelens.exe 主程序 | ✅ | ✅ |
| 指纹规则 / 字典 | ✅ | ✅ |
| 漏洞情报库（11024 条） | ✅ 内置 | ❌ 需自行放置 `data/intel_dump.json.gz` |
| Nuclei 模板库（5400+ 可运行） | ✅ 内置 | ❌ 可用 `update-nuclei` 在线拉取 |
| OSV 在线同步（update-osv） | ✅ | ✅ |
| 适用场景 | 开箱即用、离线环境 | 网络/体积受限，或自行维护情报库 |

> **full 版因情报库保密要求不进入任何托管仓库**，仅通过本地构建与线下
> 渠道（如微信文件传输）分发；lite 版可由 CI 自动构建。

## 使用

1. 解压或安装后运行 `sitelens.exe`（默认监听 http://127.0.0.1:5000）
2. 浏览器打开控制台，「设置」页可调整爬取/扫描参数、API Token、触发 OSV 同步
3. 扫描模式七档：快速 / 标准 / 深度 / 全面 / 资产测绘 / 隐匿 / 毁天灭地
   （毁天灭地为全模块 + 全量模板，仅限授权目标）

## 合规声明

- 全程只读无害验证：不注入破坏性 payload、不执行攻击 POC
- 主动模块默认关闭且有请求硬上限；内网 / 保留地址目标被 SSRF 校验拦截
- 请仅对自有或已书面授权的目标进行扫描
