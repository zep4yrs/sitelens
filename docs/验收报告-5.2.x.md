### 1.2 性能

| 项目 | 口径 |
|---|---|
| 扫描墙钟 / 请求量 | 同类目标在 `rate_mode=balanced`（默认）下的墙钟与请求数；对比 5.1 基线（效率轮既有 -36.8% 记录可复用） |

| 包体 | 安装包体积与 SHA256（`tools/release_local.sh` 出包后回填，见 release-body `【待发布】`） |

### 1.3 安全

| 项目 | 断言 |
|---|---|
| 目标校验/SSRF | `target.Validate` 私网/元数据/gov.cn 硬闸门不因 `allow_hosts` 放松 |
| 授权白名单 | 精确/通配匹配；JSON 登录端点、多步 action、批量/定时任务全部受限；零请求拒绝 |
| 凭据处理 | 认证矩阵/爆破凭据不落日志、`String()` 脱敏、头名/头值防注入 |
| 注射面 | 报告/合规/CSV/Markdown/SARIF 的动态内容转义；`data-i18n-html` 仅白名单键 |
| 发布物 | `release_local.sh` 显式 `GOOS=windows` + PE 魔数校验（防 v3.0.0 事故复现） |
| 依赖 | `govulncheck -tags onnx ./...`（CI 已含） |

## 3. 已知问题与风险

| 编号 | 问题/风险 | 影响 | 处置 |
|---|---|---|---|
| K-01 | SCA 无本地 OSV 库时 `status=unknown`（只列依赖不判漏洞） | 用户可能误读为「无漏洞」 | 报告已显式标注；发版说明写清前置条件（`SITLENS_OSV_DB`/`data/osv_db.json`） |
| K-02 | 桌面壳未 Windows 真机验收（托盘/快捷键/材质/通知） | 桌面交互可能有问题 | 发版前必须真机复测；不通过则从发行说明剔除或修 |
| K-03 | 品牌更名 FE-13 暂缓 | 文档/安装器仍为现名 | 保持「站点透视 / SiteLens」，不对外宣称更名 |
| K-04 | CP-06 持久化为文件分层 + 归档，非 SQLite/PG | 无数据库后端、无跨机共享 | 发行说明明确边界；后续版本评估 |
| K-05 | CP-02/05/07/10/11 部分为能力层，扫描器/UI 接线随后续批次 | 用户可能看不到全部能力 | 验收表逐项标；发行说明写「能力层/入口」 |
| K-06 | 页面静态文案仅 `app.html` 已标 `data-i18n`；toast/服务端报告仍中文 | 英文模式部分中文 | 发行说明标注 i18n 覆盖范围 |
| K-07 | 5.2.0 发行说明仍有 `【待发布】` 体积/SHA256 占位 | 发版检查项未闭环 | 出包后回填并复验 |
| K-08 | Windows CRLF 仓库下 `gofmt -l` 可能整文件误报 | 本地门禁误判 | 以 CI（Linux）为准；本地用 LF 副本或 `git config core.autocrlf` 复核 |
| K-09 | 浅色主题语义色小字对比度此前实测未达 AA（`.badge.ok/warn`） | a11y 部分不达标 | 若本版未修，发行说明记为已知限制并排入下一批 |
