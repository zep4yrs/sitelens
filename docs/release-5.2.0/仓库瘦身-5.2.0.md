## 3. 保留了什么（不要误删）

- **线性模型** `cve-tech.*` / `cwe-type.*` / `sev-linear.*`（约 106 MB）：默认推理必需。
- `packs/nuclei-templates.tar.gz`（46.8 MB）、`data/nvd_cves.json.gz`（30.7 MB）：离线可用必需。
- `vendor/`（24 MB，离线构建门禁）、`web/monaco/`（12 MB，Web 编辑器）。
- `sev-prior-v3.1.vocab.txt` 与 `sev-fixtures.json`（共 0.25 MB）：仅 ONNX 通道/对拍用，
  保留以便高级包与 onnx 标签测试；`.gitignore` 已忽略本地投放的 ONNX 模型与 dll。

## 4. 影响与操作

1. **所有历史提交哈希已变**：旧的本地 clone 需重新 clone，或
   `git fetch --force origin && git reset --hard origin/<branch>`；
   远端 4 个分支与 16 个标签均已 force 更新。
2. **可选 ONNX 高级包**：仓库不再携带资产。出包前手动放入
   `ml/models/go/ml_assets/sev-prior-v3.1-a.onnx`、`-b.onnx`（fp32 双种子，各约 268 MB）
   与 `ml/models/onnxruntime/onnxruntime.dll`（vocab/fixtures 已在仓库），
   再 `SITLENS_BUNDLE_ONNX=1 node build-engine.js --target=engine`。
3. **恢复旧历史/旧资产**：维护者本地留有重写前完整备份（`.git` 副本含 LFS 对象 +
   `git bundle --all`），需要时可从中恢复。
4. **远端 LFS 存储**：force push 后新 clone 不再拉取 LFS；若代码托管面板仍统计旧 LFS
   占用，需在仓库设置里清理或等待平台 GC（不影响 clone 体积）。
