# SiteLens 站点透视 — 项目答辩文档

## 一、项目定位

全类别验证型 Web 漏洞扫描器：被动指纹 → 主动验证 → 情报关联 → 网络层检测 → 源码审计，五类能力覆盖 Web 安全评估全流程。

## 二、技术架构

```
浏览器（HTML/CSS/JS 零构建）
    │ fetch / JSON
Flask（REST API + 页面路由 + 异步任务队列）
    │
    ├─ scanner/engine.py    扫描编排（校验→采集→解析→检测→评分→关联）
    ├─ scanner/checks.py    验证型检测引擎（35+ 无害 check）
    ├─ scanner/nuclei 桥    2613 条社区模板（MoE 式语义路由调度）
    ├─ scanner/taint.py     污点分析（AST 数据流追踪）
    ├─ scanner/netsec.py    TLS 证书 + DNS 邮件安全
    └─ PostgreSQL 18        指纹库/漏洞情报/扫描历史/任务队列
```

**技术栈**：Python 3.10 · Flask 3 · PostgreSQL 18 · requests · BeautifulSoup4 · PyYAML

## 三、核心亮点（答辩重点讲）

### 3.1 面向对象设计（30 分）

| 概念 | 实现位置 | 说明 |
|---|---|---|
| 封装 | models.py 全部实体 | 私有属性 + property + 受控写入 |
| 继承 | BaseDetector → 7 子类 | 按证据源分：Header/Cookie/Meta/Html/Script/Tscan/Bundle |
| 多态 | engine._run_detectors() | 统一 detect() 接口，加检测器零改引擎 |
| 组合 | ScannerEngine | 组合 Fetcher+Crawler+检测器组+Registry+VulnMatcher |

### 3.2 爬虫技术（30 分）

- requests.Session 统一 UA / 限速 / 超时重试
- BeautifulSoup 结构化解析（meta/script/DOM 选择器/CSS 类名集合）
- 同域 BFS 浅爬取（≤4 页）合并证据提高检出率
- SSRF 防护：协议白名单 + DNS 解析逐 IP 校验 + 内网/环回/保留地址拒绝

### 3.3 数据规模

| 数据 | 数量 | 来源 |
|---|---|---|
| 产品指纹 | 2850 条 | 自建 369 + TscanPlus 2481 |
| 检测类别 | 78 个 | 覆盖 CMS/框架/CDN/分析/支付等 |
| 漏洞情报 | 11024 条 | afrog 1497 + xray 488 + TscanPlus 9039 |
| CVE 索引 | 34931 行 | 微软安全公告去重 |
| KEV 在野利用 | 1695 条 | CISA 官方 JSON |

### 3.4 安全合规设计

- Server 头固定为 SiteLens（不暴露框架指纹）
- SQL 全部字面量 + 参数绑定（通过静态安全审计）
- POC 载荷不落盘、不执行（只提取元数据）
- 弱口令字典仅存档未接入功能

## 四、数据库设计

PostgreSQL 18 · 数据库名 sitelens

| 表 | 用途 |
|---|---|
| categories | 78 个检测类别 |
| technologies | 369 条自建精编指纹 |
| tscan_fingerprints | 2481 条社区模板（表达式组） |
| vuln_kb | 11024 条漏洞情报（含 256 维语义向量） |
| cve_ms | 34931 条微软公告 |
| kev | 1695 条在野利用清单 |
| scans / scan_techs | 扫描历史 + 技术明细（支持按技术检索） |
| jobs | 异步任务队列 |

模糊检索：PostgreSQL trgm 相似度（GIN 索引）+ 哈希 TF-IDF 向量余弦。

## 五、功能演示脚本（5 分钟）

1. **首页**：输入 text-well.com → 自动跳转工作台
2. **扫描**：等级选"深度识别" → 实时阶段面板 → 14 项技术 + 安全评分
3. **已验证漏洞**：Nuclei 模板命中结果展示
4. **漏洞情报**：按组件关联 + 严重度排序 + KEV 在野利用红标
5. **源码审计**：上传 .py 文件 → 污点分析 + 危险函数检测
6. **情报库**：搜"grafana" → 语义排序展示
7. **导出**：一键宽表 CSV（78 列 × N 行）

## 七、总结

SiteLens 实现了从指纹识别到漏洞情报关联的完整链路，PostgreSQL 存储全量数据，
MoE 式语义路由实现精准检测调度，同时保持了 SSRF 防护、限速合规等安全设计。
适用于授权测试、安全评估教学、企业资产测绘等场景。
