| 阶段 | 交付物 |

## 五、Leakage Check 结果

- `asof_injection`：注入晚于全部样本的 verified/intel 记录 → 4 个先验列逐值不变，PASS
- `prior_upper_bound`：每 host 首扫先验计数=0，PASS
- `blacklist`：三张特征表无未来结果字段，PASS
- `host 隔离`：LOHO 每折断言 train/test host 不相交，PASS
- `split 等价性`：127.0.0.1 有 7 个目标 URL（多端口应用）；按 URL 切分会引入
  host 级交叉 → **只保留 host split（更严口径）**，target split 不单独统计

## 六、Split 策略

- 主口径：**Leave-One-Host-Out**（10 折，host 组为隔离原子）——每行都有 OOF 预测
- 副口径：**time split 80/20**（全局时间排序；检验时间泛化，先验仍严格 as-of）
- target split：按等价性检查结论不单独统计（伪造两个重合实验被禁止）

## 七、Baseline 结果（T2：scan×candidate 排序，19 查询/19 观测正例）

| 基线 | P@5 | R@5 | nDCG@5 | P@10 | R@10 | nDCG@10 |
|---|---|---|---|---|---|---|
| severity 序 | 0.0 | 0.0 | 0.0 | 0.0053 | 0.0526 | 0.0158 |
| rule-based（Lv0+CMS 优先） | 0.0 | 0.0 | 0.0 | 0.0789 | 0.7895 | 0.2551 |
| **prior-hits（as-of 历史命中）** | **0.0947** | **0.4737** | **0.2437** | 0.0474 | 0.4737 | 0.2437 |
| random（seed 固定） | 0.0316 | 0.1579 | 0.0611 | 0.0211 | 0.2105 | 0.0777 |

真实反直觉发现：最高频命中 check 是 admin-path/login-root（info 级），
severity 序基线把它们的排名压到队尾 → P@5=0；而"该主机历史命中过"是当前
最强先验。CVSS/KEV 基线因 intel 候选无可观测结局（verified 与 intel 候选无
可靠联接：nuclei_index 无模板 yaml id 字段）只给定义不评指标——如实记录。

## 八、ML 结果（gate 放行任务）

**S1（L3 sanity 分类，966 行/12 正例）**
- LOHO 10 折；3 折跳过（测试 host=127.0.0.1 时训练折只有单一类）
- OOF 行 829 / **OOF 正例 0** → ROC-AUC/PR-AUC **不可计算**（auc_note 已写入）
  ——12 个 confirmed 全部在 127.0.0.1（靶场），跨 host 判别力无法评估
- LR OOF Brier=0.0003 → 校准判定 **unreliable**（规则：AUC≥0.55 前置；
  全零预测的退化校准无意义）→ **probability=null**

**S2（安全评分回归，111 行）**
| 模型 | LOHO MAE | time-split MAE |
|---|---|---|
| Ridge | 42.34 | 0.281 |
| GBDT | 40.04 | 0.037 |
| median 基线 | **10.0** | — |

真实结论：模型**跑输** median 基线（host 分布差异主导，10 个 host 太少）；
time split 下近乎完美（同 host 时序可预测，prior_sec_score_last 是合法
as-of 特征）——说明瓶颈是资产泛化而非时间泛化。不硬超基线，如实报告。

## 十二、主动发现并修复的问题

1. premigrate 与 history 同 id 但内容因迁移规范化有差异 → 补**事件级去重**
   （era 曾多出 11 条重复扫描事件）
2. matrix 记录与 history 共享 id 空间但事件独立 → 内容级去重规则明确分层
3. baseline 评估初版把 nuclei/passive 行计入正例（223）→ 收敛到 src=check
   且限定候选集内（19）
4. 校准判定初版"退化即 reliable"误导 → 增加 AUC≥0.55 前置条件，改判
   unreliable、probability=null
5. S2 回归预测越界（MAE 176>量程）→ 预测裁剪到 [0,100]
6. predict.py 单扫描重建特征时技术词汇表与训练期不一致 → 按训练期特征列
   重索引（schema 对齐）
7. S1 跳折未留痕 → skipped_folds/auc_note 全部记录
8. 文档（根目录）与仓规范冲突 → 归位 docs/；.gitignore 保证数据不入仓
