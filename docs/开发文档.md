# SiteLens 站点透视 — 完整开发文档

## 1. 项目定位

**SiteLens 站点透视**是一个结构完整的全类别验证型 Web 漏洞扫描器，覆盖指纹识别、漏洞验证、DAST、认证扫描、网络层检测、源码审计六大类攻击面。核心价值链：指纹识别 → 漏洞情报关联 → 安全响应头评分 → 已验证漏洞报告。

## 6. 功能模块

### 6.1 验证型检测引擎
35 条自研 check（.git 泄露/.env/actuator/swagger/phpinfo/目录列表/CORS/开放重定向等）
+ Nuclei 语义路由子集（tag 联动置顶 → 向量排序 → 轮转兜底，cap 80）。
软 404 基线过滤，命中即「已验证漏洞」。

### 6.2 漏洞情报三级判定
confirmed：版本落在 OSV/GitHub Advisory 区间内。
possible：同名提示（无版本或无区间数据）。
excluded：版本不在区间，跳过不展示。

### 6.3 安全响应头评分
8 项加权（HSTS 20/CSP 20/XFO 10/XCTO 10/RP 10/PP 10/COOP 10/CORP 10），A+~F。

### 6.4 认证扫描
Cookie 会话注入，全链路带会话执行，覆盖登录后攻击面。

### 6.5 可选主动模块
目录探测（软 404 基线+403 绕过）/ 子域名枚举（DNS 并发）/
端口服务识别（nmap banner）/ FingerDir 路径指纹。默认关。

## 12. 同类对比与改进路线

对比对象与详细分析见 `docs/Nuclei对比与借鉴.md`（引擎，MIT）与 `docs/Wapiti对比与借鉴.md`（同栈整车，GPL-2.0）。

| 维度 | Nuclei | Wapiti | SiteLens |
|---|---|---|---|
| 形态 | 检测引擎（YAML DSL） | Python 扫描器（httpx 异步） | 扫描工作台（指纹→情报→验证→资产） |
| 检测面 | 模板库 7000+，DSL/多请求/OOB | 29 主动模块（注入类深）+9 被动 | 35 check + 模板子集 + DAST 4 项 |
| 指纹/情报 | 无指纹情报层 | Wappalyzer 指纹，无情报层 | 2851 指纹 + 情报三级判定 + KEV |
| 吞吐 | 150 req/s | 异步并发 | 0.4s 限速（合规取舍） |
| 资产 | 无状态 | 无状态 | PG 全量 + diff + 多格式导出 |

双向结论：检测面广度与注入深度对手占优（如实口径）；情报层、结果资产、源码审计、合规内建是我们独有。

改进路线：
- 已落地：命中二次确认 + 回显路径剔除（防自指误报，双向独有）；多源情报与来源追踪；CVSS 本地计分
- 计划 P1：Cookie 属性（HttpOnly/SameSite）与表单 CSRF token 存在性只读检测；同路径模板请求聚类提速；子域接管指纹表（只读 DNS+CNAME 特征）
- 计划 P2：模板 extractor 版本抽取喂三级判定（验证线与情报线焊接）
- 不做：payload 注入类（与无害只读红线冲突）；GPL 代码零拷贝（只借鉴思路与数据格式）
