# SiteLens 站点透视 — 完整开发文档

## 1. 项目定位

**SiteLens 站点透视**是一个结构完整的全类别验证型 Web 漏洞扫描器，覆盖指纹识别、漏洞验证、DAST、认证扫描、网络层检测、源码审计六大类攻击面。核心价值链：指纹识别 → 漏洞情报关联 → 安全响应头评分 → 已验证漏洞报告。

## 6. 功能模块

### 6.1 验证型检测引擎
35 条自研 check（.git 泄露/.env/actuator/swagger/phpinfo/目录列表/CORS/开放重定向等）
+ Nuclei 语义路由子集（tag 联动置顶 → 向量排序 → 轮转兜底，cap 80）。
软 404 基线过滤，命中即「已验证漏洞」。

### 6.2 漏洞情报三级判定
confirmed：版本落在 OSV/GitHub Advisory 区间内。
possible：同名提示（无版本或无区间数据）。
excluded：版本不在区间，跳过不展示。

### 6.3 安全响应头评分
8 项加权（HSTS 20/CSP 20/XFO 10/XCTO 10/RP 10/PP 10/COOP 10/CORP 10），A+~F。

### 6.4 认证扫描
Cookie 会话注入，全链路带会话执行，覆盖登录后攻击面。

### 6.5 可选主动模块
目录探测（软 404 基线+403 绕过）/ 子域名枚举（DNS 并发）/
端口服务识别（nmap banner）/ FingerDir 路径指纹。默认关。

## 12. 同类对比与改进路线

对比对象与详细分析见 `docs/Nuclei对比与借鉴.md`（引擎，MIT）与 `docs/Wapiti对比与借鉴.md`（同栈整车，GPL-2.0）。

| 维度 | Nuclei | Wapiti | SiteLens |
|---|---|---|---|
| 形态 | 检测引擎（YAML DSL） | Python 扫描器（httpx 异步） | 扫描工作台（指纹→情报→验证→资产） |
| 检测面 | 模板库 7000+，DSL/多请求/OOB | 29 主动模块（注入类深）+9 被动 | 35 check + 模板子集 + DAST 4 项 |
| 指纹/情报 | 无指纹情报层 | Wappalyzer 指纹，无情报层 | 2851 指纹 + 情报三级判定 + KEV |
| 吞吐 | 150 req/s | 异步并发 | 0.4s 限速（合规取舍） |
| 资产 | 无状态 | 无状态 | PG 全量 + diff + 多格式导出 |

双向结论：检测面广度与注入深度对手占优（如实口径）；情报层、结果资产、源码审计、合规内建是我们独有。

改进路线：
- 已落地：命中二次确认 + 回显路径剔除（防自指误报，双向独有）；多源情报与来源追踪；CVSS 本地计分
- 已落地 P1：Cookie 属性/CSRF token 只读检测（passive 模块）；子域接管指纹表（takeover：18 服务 CNAME+特征页双条件判定，opt-in，候选封顶）
- 计划 P1 余项：同路径模板请求聚类提速
- 计划 P2：模板 extractor 版本抽取喂三级判定（验证线与情报线焊接）
- 不做：payload 注入类（与无害只读红线冲突）；GPL 代码零拷贝（只借鉴思路与数据格式）

## 13. Go 主干架构（v1.1.0-go 起，Python 全量实现存档于 python 分支）

Go 版以「单二进制、零外部依赖、全阈值可配」为第一原则：

| 包 | 职责 |
| --- | --- |
| cmd/sitelens | CLI：scan（全流水线 JSON 输出）/ serve（内置 Web 服务） |
| internal/server | go:embed 嵌入前端 + REST API（契约对齐 Flask 版）+ 作业调度 + X-Token 鉴权 |
| internal/engine | 十一阶段扫描编排：校验→采集→爬取→指纹→评分→check→被动→DAST→主动模块→网络层→情报 |
| internal/target | SSRF 安全校验（协议白名单/保留主机/DNS 逐 IP/重定向逐跳复检） |
| internal/httpx | 限速客户端：手动重定向 + Cookie 注入 + Set-Cookie 逐条保真 |
| internal/crawler | 同域 BFS 爬取（robots.txt Disallow 解析、页数/链接数/时长三重上限） |
| internal/htmlx | 轻量 HTML 解析（title/链接/表单含密码框标记/meta/script） |
| internal/sitelens | 指纹引擎：字面量快路径 + 正则字面量门控（5.3ms/页，370 规则） |
| internal/checks | 验证型 check（软404 基线/回显剔除/二次确认）+ JSON 插件热加载 |
| internal/dast | 参数级无害注入（XSS/SQLi/盲注双确认/重定向/遍历） |
| internal/passive | Cookie 属性 + CSRF token 被动检查（零额外请求） |
| internal/security | 8 项安全响应头加权评分（A+–F） |
| internal/modules | 目录探测（软404+403 绕过）/ 子域名枚举 / WebShell 探测 |
| internal/intel | 情报知识库：三级判定 + KEV + CVEMs + 检索 + 统计 |
| internal/versioncmp | 版本解析/比较/区间判定/抽取 |
| internal/netsec | TLS 证书与邮件安全（SPF/DMARC/MX） |
| internal/loginbrute | 登录爆破：授权闸 + 宽容表单解析 + 基线判定 |
| internal/audit | 源码审计 16 规则（RE2 兼容改写） |
| internal/store | 文件式历史存储（data/state）+ 内存作业管理 |
| internal/config | .sitelens.yml 全量阈值注册表（零值/负值回退默认） |

### 13.1 设计决策记录

1. **存储**：PG → 文件式 JSON（data/state/history.json，tmp+rename 原子写）。
   单二进制可携带；行为契约（API 字段）不变。
2. **指纹匹配性能**：字面量门控（literalGate）先以子串存在性预筛，
   仅命中候选才执行正则——剖析驱动的 2.6x 优化（bench_test.go 固化）。
3. **Set-Cookie 保真**：Go http.Header 逐条分离，替代 Python 版
   合并头启发式切分（passive 模块因此删去全部切分判据）。
4. **规则形状容错**：technologies.json 历史导出中 194/370 条 html 通道为
   {dom,html} 对象形状，加载器双形状兼容（unmarshalRules）。
5. **取消语义**：JobManager 状态轮询在引擎阶段边界与 check 循环内生效，
   取消后局部结果不入库（对齐 Flask 版行为）。

### 13.2 遗留差距（详见 docs/Go迁移对照表.md）

验证码 OCR（ddddocr）、Python 污点分析、语义向量路由（以轮转游标近似）、
Nuclei 头匹配/dsl 匹配器（word/status 已支持）。
