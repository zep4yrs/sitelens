## 三、校准过程中揪出并修复的引擎缺陷

1. **重定向逐跳校验写死 resolve=true**：本地靶场（回环/私网目标）一跳即被
   SSRF 拦截，认证扫描无法进行——修复为继承配置姿态（公网默认仍 true）。
   该问题正是历史上"本地靶场被拦三次"的同源缺陷，本次彻底修复并补齐
   httpx 测试文件（重定向跟随/SSRF 拦截/Cookie 透传）。
2. AND-merge 丢弃 status（39→28）+ 纯状态码组拒收 + stripEcho 补剔
   query 变体（28→25），详见靶场回归报告。
3. 连接失败错误信息带出底层原因（refused/timeout/SSRF 拒绝一目了然）。

## 五、已知差距（如实，1.0 前的改进清单）

1. **DVWA 认证扫描爬虫覆盖不足（1.0 首位改进项）**：带 Cookie 爬取仅回
   1 页（登录墙后的 vulnerabilities/ 全系页面未被采集）——SQLi/XSS 的
   参数级探测因此无探测点（已修：GET 表单字段合成 query URL 喂 DAST，
   待下轮矩阵验证 LFI 类之外的真实命中）；LFI/phpinfo 系经直探路径
   已命中。复现：auth_cookie + DVWA + full → res.Pages=1。方向：
   爬虫在真实 DVWA 登录态首页的链接采集插桩（单元测试证明爬虫对
   登录墙+Cookie+相对链接形态处理正确，真机差异待插桩定位）。
2. **第二个公开靶场镜像不可得**：juice-shop（ghcr denied ×5）、pikachu
   （daocloud 403 / dockerpull 缓存污染）——公开镜像源当天全线异常，
   后续镜像源恢复后补跑第二靶场列。
3. 上游模板质量噪声（zenscrape/zenserp/acme-xss 等）：引擎可自证，
   计划支持按模板 ID 黑名单过滤。
