## 三、校准过程中揪出并修复的引擎缺陷

1. **重定向逐跳校验写死 resolve=true**：本地靶场（回环/私网目标）一跳即被
   SSRF 拦截，认证扫描无法进行——修复为继承配置姿态（公网默认仍 true）。
   该问题正是历史上"本地靶场被拦三次"的同源缺陷，本次彻底修复并补齐
   httpx 测试文件（重定向跟随/SSRF 拦截/Cookie 透传）。
2. AND-merge 丢弃 status（39→28）+ 纯状态码组拒收 + stripEcho 补剔
   query 变体（28→25），详见靶场回归报告。
3. 连接失败错误信息带出底层原因（refused/timeout/SSRF 拒绝一目了然）。

### 跨轮次稳定性说明（如实）

DVWA 认证扫描三轮（r8/r11/r12）：LFI、phpinfo、open-redirect、csrf-form
等命中**逐轮有波动**（如 r8 命中 LFI 但 r12 未命中；r12 命中 phpinfo）。
原因：每轮全新容器 + setup 重置 + PHP 会话时序差异，受会话/安全级状态
影响。1.0 前改进：check 命中的会话稳定性插桩。**跨轮合并视角：LFI、
phpinfo、open-redirect、csrf-form、upload-form 五类真实缺陷全部至少
命中过一次，零误报底线保持。**
