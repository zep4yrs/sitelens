## 2. 5.2 范围（本批交付）

### PF-01 扫描前预检 + 建议卡

- **是什么**：输入 URL 完成后自动发 **1 次只读 GET**（≤3 跳、正文截断 256KB、5s 超时），提取状态/标题/服务器/WAF/技术指纹；服务端缓存（TTL 120s、上限 32、同 URL 30s 去重、in-flight 去重）；点开始扫描时把该响应**复用为首页**，扫描总请求不增加。
- **建议卡**：WAF/限流→polite 或降速率；CMS/框架→标准档+专项；静态→快速档；401/403→认证/UA 提示；慢响应→polite；跨主机→范围确认；预检失败→原因+重试，不阻断。
- **开关**：`scan.preflight`（默认 true，服务端总闸）+ 前端「输入后自动预检」开关（默认开，localStorage）。
- **验收**：预检 ≤1 请求/URL/30s；扫描首页复用后目标侧请求数 = 1；关闭开关 0 预检；失败不阻断；建议不自动改选项；`diagnostics.preflight_reused` 正确。

### NS-01 网络层 P0

- 证书：SAN/hostname 不匹配、链完整性、SHA-1 签名、RSA < 2048、有效期窗口；
- DNS 邮件：DMARC `p/quarantine/reject` 与 `rua` 解析、SPF 查找数、CAA；
- HTTP：HSTS、HTTP→HTTPS 跳转（复用一次 GET）。
- **验收**：只增加 1 次 HTTP + 少量 TXT 查询，不新增端口扫描；既有 TLS/DNS 发现语义不变。

### LB-01 登录爆破安全护栏

- 锁定关键字/429/连续失败 → **停止或指数退避**；每账号尝试上限；
- 每次 POST 前重取 hidden/CSRF token；
- 成功证据：响应差异 + Set-Cookie + 可复制 curl；
- **验收**：锁定目标不继续打；一次性 CSRF token 场景命中率不下降；证据完整；总量上限仍生效。

### AU-01 源码审计 SARIF 导出

- SARIF 2.1.0：`ruleId/level/locations/partialFingerprints`；CLI `audit --sarif` 与 API 下载；
- **验收**：GitHub code scanning 可解析；既有 JSON 报告不变。

### FE-01~03 前端设计升级（5.2 已交付）

- **FE-01 设计令牌**：`web/css/tokens.css` 单一来源（颜色/表面/圆角/间距/阴影/字体/动效/焦点环），浅/深两套；默认主题 `auto` 跟随系统；`tokens.test.mjs` 门禁接入 CI。
- **FE-02 结果页**：扫描覆盖度卡（页面/请求/去重/被拦/WAF 原因/阶段耗时 + 覆盖声明）、「证据 N/5」徽章、修复建议。
- **FE-03 扫描前/中**：扫描计划卡（目标预检/将运行项/请求量级/经验估时）、实时统计条（请求/页面/被拦/速率）、阶段时间线（DAST 长阶段不再假进度）、ETA 外推、WAF 拦截横幅。
- 说明：FE-04/05 的**基础部分**（焦点可见态、reduced-motion 降级、扫描进度反馈）已随上述工作落地；完整无障碍与动效规范在 5.3 收口。

## 3. 5.3 范围（全量）

按 backlog 表依次落地 BT-01~03、AU-02~03、NS-02、LB-02、XC-01~03。每批独立里程碑、可独立内测：

- **M1 批量**：预设/重试 → 续跑/导出/并发 → 定时/diff/通知；
- **M2 审计**：SARIF 基线/规则扩展 → SCA/多语言/自定义规则；
- **M3 网络层**：资产发现/端口并入/协议评级/批量/到期提醒；
- **M4 爆破**：多步登录/验证码/失败分类/批量/白名单；
- **M5 工作台**：统一任务中心、统一报告导出、统一安全护栏；
- **M6 前端设计升级**：无障碍/动效/质量门禁/i18n/桌面深化/包体/设计系统/响应式/状态机（FE-04~12）。

## 4. 发布与验证

- **5.2**：`feat/sitelens-5.2.0` 分支按 PF→NS→LB→AU 顺序提交（每项一 commit + 文档）；每步 `go build/vet/test`、`node --test`、CI 绿；5.2.0 发行说明标注「部分新功能」，未完成项列 5.3。
- **5.3**：`feat/sitelens-5.3.0` 分支汇总全量；发版前全量门禁（-race、govulncheck、graph、前端、Wails）、安装包/SHA256/体积记录。
- **回退**：5.2 新功能均带开关或为 additive（`scan.preflight`、SARIF 导出、batch 预设），可单独关闭；文档记录回退方式。

## 5. 风险与假设

- 5.2 新增约 6.5 人天（PF/NS/LB/AU）；FE-04a/05a 若进 5.2 再加约 2 人天。feature flag + 硬切点控制，延期优先顺延 AU-01 到 5.3。
- 预检「未点开始即发请求」：默认开但可关、只读、限流、明确文案（见《预检与建议卡》）。
- 5.3 体量大：按 M1~M6 分批，每批独立验收，不做一次性大爆炸；FE 专项约 25 人天，可与业务线并行。
- 假设 5.2.0 尚未正式出包；若已出包则本批改为 5.2.1，内容不变。

## 6. 前端设计升级（FE）专项

### 6.1 现状与差距（2026-10-30 审计）

- 全站 HTML `aria-*`/`role=` 为 **0**；键盘仅个别输入框，无全局快捷键/焦点管理。
- 设计令牌已收口（FE-01），但组件仍为原生 JS + 手写 CSS，无组件预览/契约文档。
- 动效只有少量 keyframes/transition，无统一 duration/easing 规范（已有 `prefers-reduced-motion` 降级）。
- 无前端 lint/format/视觉回归/a11y 门禁；Monaco 随包约 **9MB**（editor 3.7MB + tsWorker 5.8MB）。
- i18n 仅 `common.js` 里 zh-CN 骨架；桌面壳有 splash/updater/NSIS，缺托盘/全局快捷键/多窗口。
- 产品仍是「单次扫描工具」，缺项目/资产分组、报告 diff、定时任务（与 BT/XC 联动）。

### 6.2 5.2 已交付

FE-01/02/03（见 §2）：设计令牌 + 深色跟随系统、结果页覆盖度/证据卡、扫描前计划卡 + 扫描中实时统计。

### 6.3 5.2 剩余（可选，时间允许时）

- **FE-04a 基础无障碍**：主导航/按钮 `aria-label`、焦点可见态补齐、扫描/取消/导出快捷键（Ctrl+Enter / Esc / Ctrl+E）、配置输入 CJK IME 守卫。
- **FE-05a 动效基础**：统一 duration/easing token 到现有交互（按钮/弹层/列表）、扫描骨架屏。

> 若 5.2 排期紧张，FE-04a/05a 顺延 5.3，不阻断发布。

### 6.4 5.3 全量

- **FE-04 无障碍全量**：aria/role/焦点管理/键盘全量、对比度、屏幕阅读器走查；CJK IME 全站守卫。
- **FE-05 动效全量**：骨架屏/空态/错误态规范、列表渐入、进度微交互；`prefers-reduced-motion` 全站。

### 6.5 验收

- FE-04：axe/pa11y 0 critical；键盘可完成「输入→扫描→取消→导出」全流程；CJK IME 不误发。

- FE-06：CI 新增 lint/a11y/视觉 smoke 步骤，失败即红。
- FE-07：UI 可切中/英，文档双语。
- FE-08：托盘/快捷键/多窗口可用；FE-09 安装包体积下降（记录前后）。
- FE-10：组件预览页 + 设计契约文档；FE-11 375px 宽无横向滚动、PDF 导出正常。
- FE-12：扫描中断后可恢复/续扫，状态机无非法跳转。
