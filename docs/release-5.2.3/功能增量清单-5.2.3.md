## 3. 新增能力面（可核对）

### 3.1 内部包（8 个新包）

- `internal/afrogx`：afrog 模板 expression 求值器（rule 级匹配，1,699 条模板通过率 0→51.7%）；
- `internal/apispec`：OpenAPI / GraphQL 解析与扫描计划接线；
- `internal/authz`：RBAC / 租户 / 令牌鉴权；
- `internal/diag`：本机脱敏诊断包（`/api/diagnostics`）；
- `internal/mcp`：MCP stdio server（13 工具，辰极 Lodestar 接入）；
- `internal/protochk`：WebSocket/h2c/HTTP2 协议面检查；
- `internal/seedcmd`：引擎随包种子数据初始化；
- `internal/worker`：WorkerPool / MemoryQueue（批量与企业化）。

### 3.2 新增 HTTP API（22 条）

- 任务/资产：`GET /api/tasks`、`GET /api/assets/cert-expiry`、`GET /api/assets/ports`；
- 诊断/反馈/预检：`GET /api/diagnostics`、`POST /api/feedback`、`POST /api/preflight`；
- 批量与定时：`GET /api/batch/jobs`、`POST /api/batch/{id}/resume`、
  `GET/POST /api/batch/schedules`、`PATCH/DELETE /api/batch/schedules/{id}`、
  `POST /api/batch/schedules/{id}/run`；
- API spec：`POST /api/apispec`、`POST /api/apispec/graphql`；
- 复核/白名单：`POST/GET /api/triage/{scanID}`、`POST/DELETE/GET /api/whitelist`、
  `GET /api/whitelist/check`；
- 设计系统页：`GET /design`。

### 3.3 配置与 CLI

- 新增配置键 37 个：`scan.preflight`、`scan.rate_mode`/`rate_max_rps`、`scan.max_depth`、
  `scan.allow_hosts`、`scan.pages_retained`、`scan.graph`、`store.driver`/`dsn`、
  `web.auth_mode`/`auth_secret`、`batch.use_worker_pool`、`dast.proto`/`deser`/`logic`/`upload`/`idor`、
  `netsec.port_scan`、`active.*`、`ml.sev_linear` 等；
- CLI：`sitelens mcp`（新增子命令）；引擎/CLI 拆成 `sitelens-engine` 独立二进制；
  `audit` 支持 SARIF / 基线 / diff；`scan` 补齐 `[modules]` 接线（本轮修复）。

### 3.4 前端 / 桌面 / 底座

- 前端：设计令牌单一来源、主题跟随系统、无障碍（地标/焦点陷阱/键盘/IME）、中英 i18n、
  Monaco 懒加载、窄屏响应式与打印、状态机零丢失、triage/白名单入口、反馈页、设计页；
- 桌面 Wails：托盘快速扫描、`Ctrl+Shift+S/Q` 全局快捷键、Mica/深色标题栏、通知窗、
  引擎/壳拆分（无控制台窗）；
- 底座：Go 1.26.10（修 `crypto/x509` GO-2026-6809）、模板索引 cacheSchema v10、
  Happy Eyeballs 拨号、per-host 令牌桶限速、请求去重、诊断账本。

## 5. 为什么之前发行说明显得少

v5.2.3 原章节只写 5.2.3 自身增量；5.2.0 与第二/三批在 CHANGELOG 里是独立“未发布”章节，
发行说明只用一句“第二/三/四批收尾合并”带过。由于 5.2.0/5.2.1/5.2.2 不再发版，
本清单与发行说明已改为 **5.1.0 → 5.2.3 累计口径**；数字以上表为准。
