# SiteLens 4.0.0 升级指南

适用：从 v3.0.0 / v3.0.1 桌面版升级到 v4.0.0。命令行用户（直接克隆仓库）拉取 `v4.0.0` 标签即可，数据无需迁移。

## 方式一：自动更新（推荐）

桌面版内置自动更新。打开软件 → 设置 → 关于与更新 → 「检查更新」，或等它自己查到：

1. 提示发现新版本 v4.0.0 后，安装包在后台下载（差量优先，网络差时自动全量）
2. 下载完成会气泡提醒，点「立即重启」即完成升级（引擎一并升级）
3. 不重启不影响继续使用，下次主动退出前都会再问一次

更新源在 GitHub（desktop-stable）。网络不通时可手动升级（方式二）。

## 方式二：手动覆盖安装

1. 下载 `SiteLens-Setup-4.0.0.exe`（发布页附带 SHA256，建议比对）
2. 直接双击运行，装回原目录即可——**扫描历史、偏好、引擎配置全部保留**，
   卸载向导问「是否保留数据」时默认保留，不要改
3. 装完启动，右下角托盘图标 → 关于，确认版本为 4.0.0

## 数据与配置兼容

| 项 | 兼容性 |
|---|---|
| `.sitelens.yml` 引擎配置 | 完全兼容；4.0 新增键均有默认值，无需改动 |
| 扫描历史 `data/state/` | 完全兼容，覆盖安装即继承 |
| 模板池 / 情报库 | 与 3.0 同源同规模，无需重新下载 |
| 事实图数据 `data/state/graph/` | 4.0 新增；仅当扫描时勾选「事实图」才生成，旧扫描不受影响 |

## 4.0 的新能力怎么开

- **事实图 / 攻击链**：扫描页「验证」组勾选「事实图」后，扫描会额外收集结构化证据；
  扫完到「攻击链」页看入口点 → 发现 → 影响的关联视图，可导出 JSONL。默认不勾，
  不勾时扫描行为与 3.0 一致。
- **源码审计工作台**：工作台 → 源码审计，现在可以选**整个项目文件夹**（或拖进来），
  左边文件树、右边代码预览，有漏洞的行直接标红/黄，点发现列表跳到对应行。
- **利用级验证**：开关位置不变（设置 → 引擎配置），3.0 开过的升级后仍保持开启。

## 回滚

自动更新前不会动旧文件；手动升级想回 3.0.1：重新运行 `SiteLens-Setup-3.0.1.exe`
覆盖安装即可，数据目录不回滚也兼容（4.0 生成的事实图目录 3.0 会忽略，不报错）。

## 已知限制

- 安装包未做代码签名：Windows 首次运行若弹 SmartScreen，点「更多信息」→「仍要运行」
- 更新源仅 GitHub：大陆网络下载可能较慢，可改用手动覆盖安装
- 登录爆破的「表单单模式」暂不产出事实图实体（多模式表单不受影响）；攻击链的
  权限变化锚点暂不挂在漏洞节点上（挂在入口点），两者均不影响扫描与验证本身
