# SiteLens 设计系统与组件契约（5.2.x / FE-10）

> **本文是前端的设计契约（design contract），不是营销文档。** 目标是让新人、人类工程师
> 与 AI agent 在不读完全部 CSS/JS 的前提下，也能一致地改 UI：令牌只有一处、组件只有一份、
> 状态有矩阵、可访问性与动效有硬约定、改完知道跑什么门禁。
>
> - **事实来源（2026-11-01 快照）**：`web/css/tokens.css`、`web/css/app.css`、
>   `web/js/common.js` 与 `web/*.html`。与代码冲突时**以代码为准，并回改本文**。
> - **状态标记**：✅ 已落地｜🟡 部分落地（有债务）｜⏳ 本文定义目标、代码尚未实现（关联
>   [新功能路线图](新功能路线图-5.2.md) 的 FE-04/05/06/11）。
> - **对应路线图项**：FE-10（设计系统文档 + 设计契约），FE-04（无障碍）、FE-05（动效）、
>   FE-06（质量门禁）、FE-11（响应式/打印）。本文只收口"约定"，不新增构建链。

## 0. 一句话规则（写在最前面）

1. 颜色/圆角/间距/阴影/字体/动效**只能**在 `web/css/tokens.css` 定义，组件里用 `var()` 消费。
2. 共享组件样式**只能**在 `web/css/app.css`；页面 `<style>` 只允许放**该页布局**，不得复制组件。
3. 图标按钮必须有可访问名称；键盘必须能完成主流程；`prefers-reduced-motion` 必须降级。
4. 不引入前端框架、构建链、CDN 外链与常驻埋点——单二进制离线可用是产品红线。
5. 改完跑：`node --test web/js/esc.test.mjs web/js/scan-options.test.mjs web/js/tokens.test.mjs web/js/scan-live.test.mjs`。

## 2. 分层与文件组织

### 2.1 分层（自上而下，依赖单向）

| 层 | 文件 | 职责 | 纪律 |
|---|---|---|---|
| 令牌层 | `web/css/tokens.css` | 颜色/表面/语义色/圆角/间距/阴影/字体/动效/焦点环/布局常量；浅色 `:root` + 深色 `.dark` 两套 | 只允许 `:root` / `.dark` 两个令牌块；不许混组件样式（门禁强制） |
| 组件层 | `web/css/app.css` | 基础元素、外壳、通用组件、页面级差异收敛；`@import "/css/tokens.css"` | 只许 `var()` 消费令牌；共享组件不得复制到页面 |
| 页面层 | `web/<page>.html` 内联 `<style>` | 仅该页专属布局（如工作台三栏、设置页表单网格） | 🟡 现状仍有 7/8 页带内联样式，禁止再新增共享组件到此层 |
| 公共行为层 | `web/js/common.js` | 壳注入（顶栏/侧栏/模式行）、偏好引擎（主题/主题色/字号/语言）、`esc()`/`safeLink()`/`toast()`/`slDownload()`/`slPoll()`/`slReportError()`、Turbo 一次性区与清理注册表 | 所有页面同步引入；跨页资源必须登记 `window.slOnCleanup` |
| 页面业务层 | `web/js/app.js`、`audit.js`、`batch.js` | 工作台/审计/批量的业务逻辑与渲染 | 复用 common.js 公共函数，不各自实现 toast/转义/下载 |
| 纯函数层 | `web/js/scan-options.js`、`scan-live.js` | 无 DOM 依赖的映射/计算，`node --test` 可直接测 | 新增纯计算优先放这里并补测试 |
| 第三方 | `web/js/turbo.js`（本地内嵌）、`jszip.min.js`、`web/monaco/**` | SPA 换页 / zip 解包 / 代码编辑 | 不修改、不升级（升级单独评审），Monaco 必须懒加载（`audit.js` 已实现） |

## 3. 设计令牌（`web/css/tokens.css`）

### 3.1 使用规则

- **唯一来源**：新色值/圆角/间距/时长先加令牌，再到 `app.css` 或页面用 `var()`；禁止在组件里
  写死 `#hex`/`px` 色值。
- **两套主题**：颜色类令牌必须在 `:root`（浅）与 `.dark`（深）都定义；圆角/间距/阴影/字体/
  动效/布局两套共用。
- **主题切换**：`common.js` 读写 `localStorage["sitelens-prefs"]`（兼容旧键
  `sitelens-theme`），`light | dark | auto`（默认 `auto`，跟随 `prefers-color-scheme` 并在
  系统变化时实时切换）；`accent`（自定义主题色，覆盖 `--primary`/`--ring`）；`fontScale`
  （`sm/md/lg/xl`，经 `html[data-fs]` 生效）；`lang`（见 [i18n 规范](i18n-5.2.md)）。
- **皮肤导入导出**：设置页可导出/导入仅含 `theme/accent/fontScale/lang` 四字段的 JSON。

### 3.2 令牌清单（✅ 已落地，值以代码为准）

| 分组 | 令牌 | 浅色值 | 用途 |
|---|---|---|---|
| 表面/文字 | `--background` / `--foreground` | `#fafafa` / `#1a1a1a` | 页面底/主文字 |
| 表面/文字 | `--card` / `--muted` / `--accent` / `--secondary` | `#ffffff` / `#f8fafc` / `#f1f5f9` / `#f1f5f9` | 卡片/表头/悬停/次级按钮底 |
| 表面/文字 | `--muted-fg` / `--border` / `--input` / `--ring` | `#64748b` / `#e2e8f0` / `#ffffff` / `#3e3f3f` | 次级文字/分隔/输入底/焦点环 |
| 主色/语义 | `--primary` / `--primary-fg` | `#3e3f3f` / `#ffffff` | 主按钮与品牌动作 |
| 主色/语义 | `--ok` / `--warn` / `--danger` / `--info` | `#16a34a` / `#d97706` / `#dc2626` / `#2563eb` | 通过/警告/危险/信息 |
| 圆角 | `--radius` / `--radius-sm` / `--radius-md` / `--radius-lg` / `--radius-pill` | `.35rem` / `6px` / `10px` / `14px` / `999px` | 控件/卡片/胶囊 |

| 焦点/布局 | `--ring-w` / `--top-h` | `2px` / `50px` | 焦点环宽/顶带高 |

### 3.3 令牌门禁（✅ 已在 CI）

`web/js/tokens.test.mjs` 守三条：① `app.css` 里每个 `var(--x)` 都在 `tokens.css` 有定义；
② `tokens.css` 只允许 `:root` / `.dark` 选择器（不许混组件样式）；③ 16 个颜色令牌浅/深两套
齐全 + 动效四件套齐全。CLI 见 `.cnb.yml` 的「前端转义回归」步骤。

## 4. 组件契约

> 每个组件给出：结构（最小 HTML）→ 类与变体 → 状态 → 可访问性要求 → 使用纪律。
> 标注 ⏳ 的是**目标要求，代码尚未实现**（属 FE-04/06）。
> 所有示例中的动态内容必须走 `esc()`（HTML）或 `textContent`（文本），禁止裸拼用户输入。

### 4.1 按钮 `.btn`（✅）

```html
<button class="btn">开始扫描</button>
<button class="btn ghost small">导出</button>
<button class="btn danger small">删除</button>
<button class="btn" disabled>扫描中…</button>
```

| 项 | 约定 |
|---|---|
| 变体 | 默认=主按钮（`--primary` 底）；`.ghost`=次级（卡片底+边框）；`.small`=紧凑（6px 12px）；`.danger`=危险操作 |
| 状态 | hover 提升阴影；`:active` 位移 2px；`:disabled` 透明度 .5 + `cursor:not-allowed`；`:focus-visible` 2px `--ring` 焦点环 |
| 纪律 | 一屏一个主按钮；危险操作加确认或二次文案；**禁用必须给原因**（相邻 `.hint` 或 `title`），不得静默灰掉；禁止用 `<div onclick>` 替代 button |
| a11y | 原生 `<button>`/`<a>`；图标按钮必须有 `aria-label`⏳；快捷键见 §6.4 |

### 4.2 输入 `.url-input` / `.tb` / `.sel` / `textarea.batch-box`（✅ / 错误态 ⏳）

```html
<input class="url-input" placeholder="https://example.com" aria-label="扫描目标">
<input class="tb" placeholder="过滤">
<select class="sel">…</select>
<textarea class="batch-box"></textarea>
```

| 项 | 约定 |
|---|---|
| 尺寸 | 主输入高 46px、字 14.5px、等宽字体；`.tb` 高 38px / 13.5px；`.sel` 高 38px |
| 状态 | `:focus` 边框变 `--ring` + 3px 光晕；placeholder 用 `--muted-fg`；禁用/只读沿用浏览器语义 |
| 错误 | 校验错误用 toast + 字段提示；⏳ 字段级 `aria-invalid` + `aria-describedby`（FE-04） |
| 纪律 | 每个输入必须有可见 label 或 `aria-label`⏳；表单提交前前端做空/协议校验并给**可执行**提示 |

### 4.3 自绘下拉 `.cdd`（✅ / a11y ⏳）

```html
<div class="cdd" id="levelBox" data-value="standard">
  <button class="cdd-btn"><span class="cdd-label"><b>标准</b><span class="cdd-desc">推荐</span></span><svg class="cdd-chev">…</svg></button>
  <div class="cdd-pop">
    <button class="cdd-opt" data-v="quick"><b>快速</b><span>分钟级</span></button>
  </div>
</div>
```

| 项 | 约定 |
|---|---|
| 为什么自绘 | 选项需要"名称+一行说明"双行结构，原生 `<select>` 表达不了 |
| 交互 | 点按钮开合（`.open`）；点页面空白关闭；选中回写 `data-value` 与标签；动画 `sl-fadeUp`（`--t-med`） |
| 初始化 | `window.initCDD("levelBox", onPick)`（`common.js`，工作台与攻击链页复用） |
| a11y ⏳ | `aria-expanded` / `aria-controls` / `aria-haspopup="listbox"`；`listbox`/`option` 角色；↑↓/Home/End/Enter/Esc 键盘操作；打开后焦点入选项、关闭归还按钮（FE-04） |

### 4.4 卡片 `.card` 与区块 `.sec`（✅）

- `.card`：卡片底 + 边框 + 10px 圆角 + `--shadow-1` + 18px 内边距；用于信息块。
- `.sec` / `.sec-title`：页面分节标题（统一规则，消除跨页漂移）；`.count` 放数量。
- `.row` / `.actions`：表单行（label 170px 固定列）与按钮行。
- `.tbl-wrap`：表格横向滚动容器（卡片式边框/圆角）。

### 4.5 表格 `table.list`（✅）

| 项 | 约定 |
|---|---|
| 结构 | `.tbl-wrap > table.list > thead/tbody`；数字列用 `.mono` + `font-variant-numeric: tabular-nums` |
| 外观 | `th` 半透明表头底（`color-mix(--muted 60%)`）、行 hover 过渡 150ms、13.5px 正文 |
| 空态 | 用一行 `<td class="muted">暂无记录</td>`（列表内）或整块 `.empty`（页面级），文案必须给下一步 |
| 加载态 | 骨架行 `.skeleton`（history/intel/audit 已用）⏳ 统一为"≤300ms 不显示骨架，避免闪烁" |
| 窄屏 | 容器横向滚动，不折叠列（FE-11 验收：375px 无横向滚动的是页面，表格自身可滚动） |

### 4.6 状态卡 `.cov-card` / `.plan-card`（✅）

- 用途：结果页「扫描覆盖度」卡、工作台「扫描计划」卡；**先讲清扫了多少/有没有被拦，再进明细**。
- 结构：`.cov-head`/`.plan-head`（标题+说明）→ `.cov-grid`/`.cov-cell` 或 `.plan-items`/`.plan-item` → `.cov-note`/`.plan-warn`（语义提示）。
- 纪律：数据字段缺失（旧记录无 `diagnostics`）时**整块不渲染**（additive），不显示空壳；被 WAF/限流拦截 >0 必须显式提示"可能造成漏报"；`.danger`/`.warn` 只用于真异常。
- 数据来源：`Result.Diagnostics`（见 [前端设计令牌与覆盖度](前端设计令牌与覆盖度.md) §2、`internal/engine/efficiency.go`）。

### 4.7 提示条 toast（✅）与错误出口

| 项 | 约定 |
|---|---|
| API | `window.toast(msg, cls)`，`cls ∈ {ok, err}`，单例 `#sl-toast`，2.6s 自动消失（`common.js`） |
| 用法 | 轻量操作反馈（已复制/已导出/已应用建议）；**长文案与需要用户处理的问题不用 toast** |
| 错误分级 | 引擎请求统一走 `window.slReportError(err)`：网络失败 / HTTP 错误 / 非 JSON 三类文案必须可区分 |
| 引擎不可达 | `slReportError` 检测到"无法连接引擎服务"时显示全屏界面态（`role="alert"`），而不是只弹 toast |
| a11y ⏳ | toast 容器 `role="status"`、错误用 `aria-live="assertive"`；禁止把焦点移走（FE-04） |

### 4.8 徽章 `.badge` 与严重度（✅）

```html
<span class="badge ok">低危</span>  <span class="badge warn">中危</span>
<span class="badge danger">高危</span>  <span class="badge info">信息</span>
<span class="badge acc">模型</span>  <span class="badge">NVD</span>
```

- 语义映射：`.ok` 通过/低危、`.warn` 警告/中危、`.danger` 危险/高危、`.info` 信息、
  `.acc` 模型来源（随主题色）、无修饰=中性。
- 统一入口：`window.sevBadge(sev, zh)`（high/critical→danger、medium→warn、其余→ok；中文标签
  由调用方或默认映射提供）。**服务端 `severity_zh` 是中文来源**，英文标签属 i18n 范围。
- 纪律：徽章文字 ≤6 个汉字；颜色不是唯一信息载体（必须带文字）；新增语义色先加令牌。

### 4.9 标签/页签 `.chip` / `.tabs` / `.tabpanel`（✅）

- `.chip`：筛选标签/可选胶囊（等宽字体、圆角胶囊、hover 变 accent）；选中态用 `.active`（按需）。
- `.tabs` + `.tabpanel`：页内页签；`.tabpanel.active` 才显示；工作台模式行另用 `.tw-modes .tab`。
- a11y ⏳：页签 `role="tablist"/"tab"/"tabpanel"` + `aria-selected` + ←/→ 切换（FE-04）。

### 4.10 空态 `.empty`、骨架 `.skeleton`、进度 `.progressbar`（✅ / 统一 ⏳）

| 组件 | 现状 | 约定 |
|---|---|---|
| `.empty` | 居中 46vh、`.big` 字形图标（`▷ ⌕ ∅ ⊘ ✕`）+ 文案 | 必须回答"为什么空 + 下一步做什么"；同一页空态只用一种形态 |
| `.skeleton` | 灰底 + 1.4s shimmer；history/intel/audit/app 已用 | 仅加载态用；`prefers-reduced-motion` 下停止动画；⏳ 与 `.hint`"加载中"不叠加使用 |
| `.progressbar` | 8px 胶囊、`width` 过渡 .5s | 只表示可量化进度；不可量化阶段用阶段时间线（扫描页已有） |

### 4.11 外壳：顶栏 / 左栏模式行 / 双区壳（✅）

| 区域 | 类 | 约定 |
|---|---|---|
| 工作台双区壳 | `.tw-app > .tw-left + .tw-toolbar + .tw-canvas` | 固定满视口；左栏 302px（`container-type:inline-size`，窄于 336px 时模式行收图标）；工具条高 50px 与顶带同高 |
| 被动页顶栏 | `.wb-top > .top-nav + .top-right` | 只放被动/管理页（设置/反馈/情报/历史/攻击链）；主动功能在左栏模式行 |

## 6. 可访问性（a11y）约定

### 6.1 目标与适用范围

目标 **WCAG 2.1 AA**（桌面 WebView2 环境），重点条款：

| 条款 | 要求 | 本项目落点 |
|---|---|---|
| 1.4.3 对比度 | 正文 ≥4.5:1；大字号（≥18.66px 或 ≥14pt 粗体）≥3:1 | 令牌色对，见 §6.3 实测 |
| 1.4.11 非文本对比度 | 控件边界/焦点环 ≥3:1 | `--border` / `--ring` |
| 2.1.1 键盘 | 全部功能键盘可达 | 主流程闭环（FE-04 验收） |
| 2.4.3 焦点顺序 | 逻辑顺序、无键盘陷阱 | 弹层/下拉/界面态需实现焦点管理 |
| 2.4.7 焦点可见 | 键盘焦点必须可见 | ✅ `:focus-visible` 已全局（2px `--ring` + 2px offset） |
| 3.3.2 标签 | 输入必须有可见标签或可访问名称 | ⏳ 字段级补齐 |
| 4.1.2 名称/角色/值 | 自定义控件要有角色与状态 | ⏳ `.cdd` / 页签 / toast |
| 2.3.3 动效 | 尊重减少动效偏好 | ✅ 全局 `prefers-reduced-motion` 降级 |

## 7. 动效规范

### 7.1 令牌与用途（✅）

| 令牌 | 值 | 适用 |
|---|---|---|
| `--t-fast` | 150ms | hover/按压/淡入页面切换帧 |
| `--t-med` | 250ms | 弹层/下拉展开、列表/卡片入场、下划线 |
| `--t-slow` | 400ms | 页面级大块过渡（保守使用） |
| `--ease` | `cubic-bezier(0.2,0,0,1)` | 全站签名缓动（无 overshoot） |

### 7.2 硬约定

1. **入场**：淡入 + 上移 ≤8px，一次性；不做循环装饰（品牌呼吸点 `.brand .dot` 2.4s 为既有例外，新增需评审）。
2. **列表级联**：前 12 项按 25ms 步进，总预算 ≤300ms；之后直接呈现（`app.css` 已实现）。
3. **禁止** `linear` 空间位移、弹跳/回弹、无限循环加载动画（骨架 shimmer 除外，且 reduce 下停止）。
4. **骨架屏**：仅加载态；shimmer 1.4s；减少动效时静止（保留底灰）。
5. **微交互**：按钮 `:active` 位移 2px 为品牌手感，保留；新交互不得叠加超过 2 个属性动画。
6. **减少动效**：`prefers-reduced-motion: reduce` 下所有 animation/transition 时长压到 .01ms、循环次数 1（✅ 全局已实现）；**保留透明度变化**以维持状态可感知。
7. **状态优先**：能用静态样式表达的状态不用动画（如 disabled 不加呼吸效果）。

### 7.3 现状债务（🟡）

| 债务 | 规模 | 目标 |
|---|---|---|
| 硬编码时长 | `app.css` 27 处 + 页面 8 处 = 35 处（如 `.toast{transition:all .25s}`、`.top-nav a{transition:color .2s}`） | 全部替换为 `var(--t-*)`，过渡属性收敛到 `color/background/box-shadow/transform` |
| linear 过渡 | `.progressbar i{transition:width .5s ease}`（进度条允许，但应显式注释为例外） | 保留但注明例外与原因 |

### 7.4 验收（FE-05）

- 全站 `grep` 不再出现裸 `Xms`/`Xs` 动效时长（令牌文件除外）。
- reduce 模式下录屏确认无位移/循环动画，状态变化仍可见。
- 骨架屏覆盖扫描中/结果加载两类等待。

## 9. 贡献流程（人类 / AI agent 可执行）

### 9.1 改动前

1. 读本文 §0/§3/§4，确认改动属于「令牌 / 组件 / 页面布局 / 页面业务」哪一层。
2. 搜一遍是否已有同类组件（`app.css` 组件段 + `common.js` 公共函数），**先复用再新增**。
3. 若需要新色/新时长/新圆角 → 先加令牌（两套主题），否则停下来评审。

### 9.2 实施步骤

| 步骤 | 动作 | 验证 |
|---|---|---|
| 1 | 令牌：`web/css/tokens.css` 增/改（浅+深） | `node --test web/js/tokens.test.mjs` |
| 2 | 组件：`web/css/app.css` 对应段落增改；页面 `<style>` 只写布局 | 浅/深主题目测 + 窄屏 |
| 3 | 页面：语义化 HTML + `common.js` 公共函数（`esc`/`toast`/`slDownload`/`slPoll`） | 控制台无报错；Turbo 换页后无重复监听 |
| 4 | 交互/快捷键/IME：遵守 §6.4 | 键盘走查 + 中文输入法回车测试 |
| 5 | 动效：只用令牌，遵守 §7 | reduce 模式录屏 |
| 6 | 文档：更新本文组件表；涉及结果页/覆盖度时同步 [前端设计令牌与覆盖度](前端设计令牌与覆盖度.md) | — |
| 7 | 提交：`feat(web): …` / `fix(web): …`；UI 改动附前后截图（发版门禁要求） | PR/评审 |

### 9.3 评审 checklist（每条都是阻塞项）

- [ ] 没有新增裸色值/裸时长/裸圆角；新令牌深浅两套齐全。
- [ ] 没有把共享组件复制到页面 `<style>`；没有新增内联 `style=`（动态值除外）。
- [ ] 可访问名称/角色/键盘/焦点可见达到 §6 约定；对比度不降级。
- [ ] 动效只用 `var(--t-*)`，reduce 下正常。
- [ ] 用户内容经 `esc()` / `textContent`；外部链接经 `safeLink()`（仅 http/https）。
- [ ] Turbo 换页安全：一次性区守卫、`slOnCleanup` 登记清理。
- [ ] 空/加载/错误/禁用/部分五种状态按 §5 实现。
- [ ] 文档与门禁同步（tokens/i18n/覆盖度文档），CI 全绿。

### 9.4 AI agent 执行契约（十铁律）

1. 只改 `web/` 与 `docs/` 相关文件；**不引入依赖、不建构建配置、不联网取素材**。
2. 令牌先行：没有令牌就不写组件样式。
3. 单文件单一职责：组件进 `app.css`、纯函数进 `scan-*.js`、公共行为进 `common.js`。
4. 不改 `web/monaco/**`、`turbo.js`、`jszip.min.js`。
5. 所有动态文本转义；不拼 HTML 字符串给用户数据（除既有 `esc()` 模式）。
6. 不改品牌资产与产品红线（无埋点、政府站硬保护、离线可用）。
7. 不"顺手"重排/压缩整份 CSS；改动最小化并带分节注释。
8. 改完必须跑前端测试四件套 + `node --test tools/ci_pipeline_guard.test.mjs`。
9. 文档必须与实现同批更新（本文/覆盖度/i18n），不允许"代码先走、文档后补"跨版本。
10. 不确定的能力（组件预览页、a11y 全量、i18n 接线）标 ⏳ 并写进路线图，不假装已实现。
